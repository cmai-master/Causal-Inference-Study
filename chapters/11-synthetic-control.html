합성 통제법 (Synthetic Control Method)

단일 처치 단위의 인과 효과 추정을 위한 혁신적 방법

🎯 왜 합성 통제법인가?

정책이나 사건이 하나의 지역/국가/조직에만 영향을 미칠 때, 적절한 비교 대상(대조군)을 찾기 어렵습니다. 합성 통제법은 여러 미처치 단위의 가중 평균으로 합성 대조군을 만듭니다.

핵심 아이디어

합성 통제:

Ŷ0t = Σ wj Yjt

wj: 최적 가중치 (wj ≥ 0, Σwj = 1)
처치 전 기간에 처치 단위와 가장 유사하도록 선택

가중치 최적화

minW ||X1 - X0W||V

X1: 처치 단위의 예측 변수
X0: 대조 풀의 예측 변수
V: 가중치 행렬

Python 
from SyntheticControlMethods import Synth

# 합성 통제
sc = Synth(
    dataprep_out=dataprep,
    optim_method='Nelder-Mead'
)

# 가중치 추정
sc.fit()

# 효과 추정
treatment_effect = sc.att()

통계적 추론: Placebo Tests

전통적 통계적 추론이 불가능하므로 위약 검정을 사용합니다.

  • In-space placebo: 각 대조 단위를 처치 단위로 가정
  • In-time placebo: 가짜 처치 시점 설정

대표 연구: Abadie et al. (2003) - 테러와 경제

바스크 지역의 테러가 경제에 미친 영향
처치: 바스크, 대조: 스페인 다른 지역들의 가중 평균
결과: 1인당 GDP 약 10% 감소

확장 방법

  • Augmented SC (Ben-Michael et al., 2021): 회귀 조정 추가
  • Penalized SC (Abadie & L'Hour, 2021): 정규화
  • Matrix Completion: 다중 처치 단위
