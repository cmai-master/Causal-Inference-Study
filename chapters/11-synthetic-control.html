🎯 왜 합성 통제법인가?

합성 통제법(Synthetic Control Method, SCM)은 정책이나 사건이 단 하나의 단위(국가, 주, 도시 등)에만 영향을 미칠 때 인과 효과를 추정하는 혁신적인 방법입니다.

💡 핵심 아이디어

문제: 캘리포니아주만 금연법을 시행했다면, 무엇과 비교해야 할까요?

해결책: 다른 여러 주들의 가중 평균으로 "합성 캘리포니아"를 만들어, 실제 캘리포니아와 비교합니다!

전통적 방법의 한계

❌ 단순 DiD의 문제

문제:

  • 적절한 단일 대조군을 찾기 어려움
  • 어떤 주도 캘리포니아와 완벽히 유사하지 않음
  • 평행 추세 가정이 의심스러움

✅ Synthetic Control의 장점

해결책:

  • 여러 대조 단위의 가중 평균 사용
  • 처치 전 기간에 최적으로 맞춤
  • 명확한 비교 대상 생성
  • 투명한 가중치

언제 Synthetic Control을 사용하나?

적합한 상황:

  • 처치 단위가 1개 (또는 매우 적음)
  • 대조 풀에 여러 미처치 단위 존재
  • 처치 전 기간의 데이터가 충분함
  • 처치가 집합 수준에서 발생 (국가, 주, 도시)

실생활 예시

연구 처치 단위 처치 결과
Abadie et al. (2010) 캘리포니아 Proposition 99 (담배세) 담배 소비
Abadie et al. (2003) 바스크 지역 테러 시작 1인당 GDP
Abadie et al. (2015) 독일 통일 경제 성장
Cavallo et al. (2013) 재해 피해 국가 자연재해 GDP

📐 Synthetic Control의 수학적 구조

기본 설정

데이터 구조:

  • J+1 개 단위 (1개 처치 + J개 대조)
  • T 개 시점 (T₀ 처치 전 + T₁ 처치 후)
  • 단위 1이 T₀+1 시점에 처치

반사실 결과

처치 단위의 처치 없었을 때 결과:

Y1t(0) = δt + θtZ1 + λtμ1 + ε1t

δt: 시간 고정효과
Z1: 관측된 공변량
λtμ1: 관측되지 않은 요인
ε1t: 일시적 충격

합성 통제 구성

대조군의 가중 평균으로 합성 대조군을 만듭니다:

가중치 벡터 W:

W = (w2, w3, ..., wJ+1)

제약조건:
wj ≥ 0 (음수 불가)
Σwj = 1 (합이 1)

합성 결과:

Ŷ1t(0) = Σj=2J+1 wj Yjt

합성 대조군 = 실제 대조군들의 가중 평균

처치 효과 추정

α̂1t = Y1t - Ŷ1t(0)

= 실제 처치 단위 - 합성 대조군

⚙️ 가중치 최적화

핵심 질문: 어떻게 최적의 가중치 W를 선택할 것인가?

방법 1: 결과 변수 매칭

처치 전 기간의 결과 변수를 최대한 잘 맞추는 가중치를 찾습니다.

minW Σt=1T₀ (Y1t - ΣwjYjt)²

처치 전 기간의 평균 제곱 오차 최소화

방법 2: 예측 변수 매칭 (Abadie et al.)

결과 변수의 예측 변수(공변량)들을 맞춥니다.

minW ||X1 - X0W||V

X1: 처치 단위의 예측 변수 (k×1 벡터)
X0: 대조 풀의 예측 변수 (k×J 행렬)
V: 예측 변수 가중치 행렬 (k×k)

예측 변수 예시:

  • 처치 전 여러 시점의 결과 변수
  • 인구, GDP, 교육 수준 등 공변량
  • 산업 구조, 지리적 특성

💡 V 행렬 선택

V 행렬은 각 예측 변수의 중요도를 결정합니다.

일반적 방법:

  • Data-driven: 처치 전 결과 변수의 MSPE를 최소화하는 V 선택
  • Equal weights: V = I (모든 변수에 동일 가중치)
  • Regression: 회귀계수를 기반으로 V 설정

실제 최적화 과정

Step 1: V 선택

처치 전 기간의 결과 변수 예측 정확도를 최대화하는 V를 찾습니다.

Step 2: W 계산

선택된 V에 대해 ||X₁ - X₀W||_V를 최소화하는 W를 계산합니다.

Step 3: 검증

합성 대조군이 처치 단위를 얼마나 잘 재현하는지 확인합니다.

📊 통계적 추론: Placebo Tests

Synthetic Control은 단일 처치 단위를 다루므로 전통적인 표준오차나 p-값 계산이 불가능합니다.

⚠️ 통계적 추론의 문제

N=1 (처치 단위 1개)이므로 중심극한정리를 적용할 수 없습니다. 대신 Placebo tests로 추론합니다.

1. In-Space Placebo Test

아이디어: 대조 풀의 각 단위를 "가짜 처치 단위"로 가정하고 동일한 분석을 반복합니다.

절차:

  1. 대조군 j를 처치 단위로 가정
  2. 나머지 대조군으로 합성 j 생성
  3. 처치 효과 α̂j 계산
  4. 모든 j에 대해 반복

결과: J+1개의 처치 효과 분포 생성

해석:

  • 실제 처치 단위의 효과가 placebo 효과들보다 극단적이면 유의미
  • P-value = (실제보다 큰 placebo 효과의 수) / (전체 단위 수)

p-value = (Σ I(|α̂j| ≥ |α̂1|)) / (J+1)

2. In-Time Placebo Test

아이디어: 처치 전 시점에 가짜 처치를 설정하여 방법이 거짓 양성을 만들어내는지 확인합니다.

절차:

  1. 처치 전 시점 t' < T₀를 가짜 처치 시점으로 설정
  2. t'까지만 데이터 사용하여 합성 대조군 구성
  3. t' 이후의 "처치 효과" 계산
  4. 효과가 0에 가까워야 함

결과: 0에서 유의하게 다르면 사전 매칭이 불량하거나 방법이 부적절

시각적 검증

Gap Plot

처치 단위와 합성 대조군의 차이를 시간에 따라 그립니다.

처치 전: 차이가 0에 가까워야 함
처치 후: 차이가 크면 처치 효과

Placebo Gap Plot

모든 placebo 단위들의 gap을 함께 그립니다.

실제 처치 단위의 gap이 다른 것들보다 크게 튀어야 유의미

💻 Python 구현

Python 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.optimize import minimize

# =========================================
# 데이터 생성 (예시)
# =========================================

np.random.seed(42)

# 단위: 1개 처치 + 10개 대조
# 시점: 20개 (10개 전 + 10개 후)
n_donors = 10
T = 20
T0 = 10  # 처치 전 기간

# 결과 변수 생성
data = pd.DataFrame()

# 처치 단위
treated_pre = 100 + 2 * np.arange(T0) + np.random.normal(0, 3, T0)
treated_post = treated_pre[-1] + 2 * np.arange(1, T-T0+1) - 15 + np.random.normal(0, 3, T-T0)
# 처치 효과 = -15

treated = np.concatenate([treated_pre, treated_post])
data['treated'] = treated

# 대조 단위들
for j in range(n_donors):
    # 각 대조군은 약간 다른 수준과 추세
    level = np.random.uniform(80, 120)
    trend = np.random.uniform(1.5, 2.5)

    donor = level + trend * np.arange(T) + np.random.normal(0, 3, T)
    data[f'donor_{j+1}'] = donor

data['time'] = np.arange(T)
data['post'] = (data['time'] >= T0).astype(int)

# =========================================
# Synthetic Control 추정
# =========================================

# 예측 변수: 처치 전 결과 변수
X1 = treated_pre.reshape(-1, 1)  # k×1
X0 = data[[f'donor_{j+1}' for j in range(n_donors)]].iloc[:T0].values.T  # k×J

# 목적 함수: ||X1 - X0*W||^2
def objective(W):
    return np.sum((X1.flatten() - X0.T @ W)**2)

# 제약조건
constraints = [
    {'type': 'eq', 'fun': lambda W: np.sum(W) - 1}  # 합 = 1
]
bounds = [(0, 1) for _ in range(n_donors)]  # 0 <= w_j <= 1

# 초기값
W0 = np.ones(n_donors) / n_donors

# 최적화
result = minimize(objective, W0, method='SLSQP',
                  bounds=bounds, constraints=constraints)

weights = result.x
print("Optimal weights:")
for j, w in enumerate(weights):
    if w > 0.01:  # 의미있는 가중치만 출력
        print(f"  Donor {j+1}: {w:.3f}")

# 합성 대조군 생성
synthetic_control = data[[f'donor_{j+1}' for j in range(n_donors)]].values @ weights

# =========================================
# 처치 효과 추정
# =========================================

treatment_effect = treated - synthetic_control
post_treatment_effect = treatment_effect[T0:].mean()

print(f"\nAverage post-treatment effect: {post_treatment_effect:.2f}")
print(f"True effect: -15.00")

# =========================================
# 시각화
# =========================================

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 원본 vs 합성
ax1 = axes[0]
ax1.plot(data['time'], treated, 'o-', label='Treated', linewidth=2, color='#e74c3c')
ax1.plot(data['time'], synthetic_control, 's--', label='Synthetic Control',
         linewidth=2, color='#3498db')
ax1.axvline(x=T0-0.5, color='gray', linestyle='--', alpha=0.7, label='Treatment')
ax1.set_xlabel('Time')
ax1.set_ylabel('Outcome')
ax1.set_title('Treated vs Synthetic Control')
ax1.legend()
ax1.grid(alpha=0.3)

# Gap (처치 효과)
ax2 = axes[1]
ax2.plot(data['time'], treatment_effect, 'o-', linewidth=2, color='#2c3e50')
ax2.axvline(x=T0-0.5, color='gray', linestyle='--', alpha=0.7)
ax2.axhline(y=0, color='red', linestyle='--', alpha=0.7)
ax2.fill_between(data['time'][T0:], 0, treatment_effect[T0:],
                  alpha=0.3, color='#e74c3c')
ax2.set_xlabel('Time')
ax2.set_ylabel('Gap (Treated - Synthetic)')
ax2.set_title('Treatment Effect Over Time')
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

# =========================================
# In-Space Placebo Test
# =========================================

placebo_effects = []

for j in range(n_donors):
    # Donor j를 처치 단위로 가정
    placebo_treated = data[f'donor_{j+1}'].values

    # 나머지 donors로 합성 대조군 구성
    other_donors = [f'donor_{k+1}' for k in range(n_donors) if k != j]

    X1_placebo = placebo_treated[:T0].reshape(-1, 1)
    X0_placebo = data[other_donors].iloc[:T0].values.T

    def obj_placebo(W):
        return np.sum((X1_placebo.flatten() - X0_placebo.T @ W)**2)

    constraints_p = [{'type': 'eq', 'fun': lambda W: np.sum(W) - 1}]
    bounds_p = [(0, 1) for _ in range(len(other_donors))]
    W0_p = np.ones(len(other_donors)) / len(other_donors)

    result_p = minimize(obj_placebo, W0_p, method='SLSQP',
                        bounds=bounds_p, constraints=constraints_p)

    synthetic_p = data[other_donors].values @ result_p.x
    gap_p = placebo_treated - synthetic_p

    # 처치 후 평균 효과
    placebo_effect = gap_p[T0:].mean()
    placebo_effects.append(placebo_effect)

# P-value 계산
observed_effect = np.abs(post_treatment_effect)
extreme_count = np.sum(np.abs(placebo_effects) >= observed_effect)
p_value = (extreme_count + 1) / (n_donors + 1)

print(f"\nPlacebo test p-value: {p_value:.3f}")

# 시각화
plt.figure(figsize=(10, 6))
plt.hist(placebo_effects, bins=15, alpha=0.6, color='#3498db',
         label='Placebo effects')
plt.axvline(x=post_treatment_effect, color='#e74c3c', linewidth=3,
            label=f'Actual effect: {post_treatment_effect:.2f}')
plt.xlabel('Treatment Effect')
plt.ylabel('Frequency')
plt.title('In-Space Placebo Distribution')
plt.legend()
plt.grid(alpha=0.3)
plt.show()

# Placebo gap 플롯
gaps_data <- data.frame()

gaps_data <- rbind(gaps_data, data.frame(

# Placebo 단위들
for (region in names(placebo_results)) {
  pr <- placebo_results[[region]]
  Y1_p <- pr$dataprep$Y1plot
  Y0_p <- pr$dataprep$Y0plot %*% pr$synth$solution.w
  gap_p <- Y1_p - Y0_p

  gaps_data <- rbind(gaps_data, data.frame(
    year = as.numeric(rownames(Y1_p)),
    gap = as.numeric(gap_p),
    unit = paste0("Region_", region),
    type = "Placebo"
  ))
}

📚 실제 연구 사례

1. Abadie et al. (2010) - Proposition 99 (캘리포니아 담배세)

연구 질문: 담배세 인상이 흡연율을 감소시켰는가?

처치 단위: 캘리포니아

처치: 1988년 Proposition 99 (담배세 25센트 인상 + 금연 프로그램)

대조 풀: 미국의 다른 38개 주

결과: 1인당 담배 소비량 (갑/년)

합성 캘리포니아 구성:

  • 네바다: 0.234
  • 콜로라도: 0.164
  • 유타: 0.239
  • 뉴멕시코: 0.153
  • 몬타나: 0.210
  • 기타: 0 (사용되지 않음)

핵심 발견:

  • 1988년 이후 캘리포니아의 담배 소비가 합성 대조군보다 약 20갑/년 적음
  • 1988년 이전: 실제와 합성이 거의 완벽하게 일치
  • Placebo tests: 다른 주들에서는 이런 효과가 관측되지 않음
  • 결론: Proposition 99가 흡연율 감소에 실제로 기여

2. Abadie & Gardeazabal (2003) - 바스크 지역 테러와 경제

연구 질문: 테러 활동이 경제 성장에 미친 영향은?

처치 단위: 바스크 지역 (스페인)

처치: 1970년대 초 ETA 테러 활동 격화

대조 풀: 스페인의 다른 16개 지역

결과: 1인당 GDP

합성 바스크 구성:

  • 카탈루냐: 0.851
  • 마드리드: 0.149
  • 기타: 0

핵심 발견:

  • 1970년 이전: 합성과 실제가 거의 완벽 일치
  • 1975년 이후: 실제 바스크 GDP가 합성보다 약 10% 낮음
  • 1인당 GDP 손실: 약 $2,000-3,000
  • 1998년 휴전 기간: Gap이 일시적으로 감소 (역효과 증거)
  • 결론: 테러가 경제에 상당한 부정적 영향

3. Abadie et al. (2015) - 독일 통일의 경제적 효과

연구 질문: 독일 통일이 서독 경제에 미친 영향은?

처치 단위: 서독

처치: 1990년 독일 통일

대조 풀: OECD 국가들

결과: 1인당 GDP

핵심 발견:

  • 통일 직후: 서독 GDP가 합성 대조군보다 약간 낮음
  • 2000년대 초반: Gap이 최대 약 12%
  • 2000년대 중반 이후: Gap 감소, 회복 조짐
  • 결론: 통일이 서독 경제에 단기적으로 부담, 장기적으로는 회복

🆕 확장 방법론

1. Augmented Synthetic Control (Ben-Michael et al., 2021)

아이디어: Synthetic Control + Outcome Regression

합성 대조군이 완벽하지 않을 때 회귀 조정을 추가하여 편향을 줄입니다.

R 
library(augsynth)

# Augmented Synthetic Control
aug_syn <- augsynth(
  gdpcap ~ treatment | regionno + year,
  data = panel_data,
  progfunc = "Ridge",  # Ridge regression for augmentation
  scm = TRUE
)

summary(aug_syn)

2. Penalized Synthetic Control (Abadie & L'Hour, 2021)

아이디어: L1/L2 정규화로 가중치를 희소하게 만들기

적은 수의 대조 단위만 사용하도록 유도하여 해석 가능성 향상

3. Matrix Completion (Athey et al., 2021)

아이디어: 여러 처치 단위를 동시에 다루기

패널 데이터를 저차원 행렬로 근사하여 반사실 결과 추정

R 
library(gsynth)

# Generalized Synthetic Control (Matrix Completion)
gsynth_out <- gsynth(
  Y ~ D + X1 + X2,
  data = panel_data,
  index = c("unit", "time"),
  force = "two-way",  # Two-way fixed effects
  CV = TRUE,  # Cross-validation for factors
  r = c(0, 5),  # Number of factors to try
  se = TRUE,
  inference = "parametric",
  nboots = 1000
)

plot(gsynth_out, type = "gap")

4. Robust Synthetic Control

  • Trimmed weights: 극단적인 가중치 제거
  • Multiple pre-periods: 여러 사전 기간으로 안정성 확인
  • Placebo-based inference: 더 보수적인 추론

⚠️ Synthetic Control 사용 시 주의사항

1. 사전 매칭 품질

문제: 합성 대조군이 처치 전 기간을 잘 재현하지 못하면 추정이 편향됩니다.

해결책:

  • 처치 전 RMSPE (Root Mean Squared Prediction Error) 확인
  • 시각적으로 처치 전 추세 비교
  • RMSPE가 크면 결과 신뢰하기 어려움

2. 외삽 (Extrapolation) 문제

처치 단위가 대조 풀의 볼록 껍질(convex hull) 밖에 있으면 외삽이 발생합니다.

예시:

  • 처치 단위의 특성이 극단적 (모든 대조군보다 높거나 낮음)
  • 이 경우 합성 대조군이 처치 단위를 잘 재현하기 어려움

해결책:

  • 예측 변수 테이블에서 처치 단위가 대조 풀 범위 내에 있는지 확인
  • 범위 밖이면 결과 해석에 주의

3. 희소한 가중치 (Sparse Weights)

가중치가 소수의 단위에 집중되는 것이 일반적이며 바람직합니다.

  • 해석이 쉬움 (어떤 단위들이 중요한지 명확)
  • 과적합 방지
  • 대부분의 가중치가 0이어도 괜찮음

4. 동시 발생 사건 (Concurrent Events)

처치 시점에 다른 사건도 발생했다면 효과를 분리하기 어렵습니다.

예시:

  • 담배세 인상 + 금연 캠페인 동시 시행
  • 어떤 정책의 효과인지 불명확

해결책:

  • 배경 지식으로 판단
  • 추가 분석 (시차가 다른 정책 비교)

5. 긴 처치 후 기간

  • 처치 후 기간이 매우 길면 다른 요인들이 개입할 가능성 증가
  • 합성 대조군의 외삽이 더 불확실해짐
  • 권장: 단기-중기 효과 추정에 초점

📝 퀴즈: 학습 내용 확인

Q1. Synthetic Control Method가 적합한 상황은?

A. 처치 단위가 수백 개인 경우
B. 처치 단위가 1개이고, 여러 미처치 단위가 있는 경우
C. 처치 전 데이터가 없는 경우
D. 무작위 배정이 가능한 경우
정답: B
Synthetic Control은 처치 단위가 1개(또는 매우 적음)이고, 여러 미처치 단위가 대조 풀로 존재하며, 처치 전 기간의 데이터가 충분한 경우에 적합합니다.

Q2. 합성 대조군의 가중치에 대한 설명으로 옳은 것은?

A. 모든 대조 단위에 동일한 가중치를 부여해야 한다
B. 가중치는 0 이상이고 합이 1이어야 하며, 소수의 단위에 집중될 수 있다
C. 가중치는 음수일 수 있다
D. 가중치의 합은 100이어야 한다
정답: B
합성 대조군의 가중치는 w_j ≥ 0이고 Σw_j = 1입니다. 가중치가 소수의 단위에 집중되는 것(sparse weights)은 일반적이며 해석에도 유리합니다.

Q3. In-Space Placebo Test의 목적은?

A. 최적 가중치를 찾기 위해
B. 관측된 효과가 통계적으로 유의미한지 검증하기 위해
C. 처치 시점을 결정하기 위해
D. 대조군의 수를 늘리기 위해
정답: B
In-Space Placebo Test는 대조 풀의 각 단위를 가짜 처치 단위로 가정하여 동일한 분석을 반복함으로써, 실제 처치 단위의 효과가 우연에 의한 것이 아니라 통계적으로 유의미한지 검증합니다.

Q4. Abadie et al. (2010) Proposition 99 연구의 주요 발견은?

A. 담배세가 흡연에 영향을 미치지 않았다
B. 담배세 인상으로 캘리포니아의 담배 소비가 유의미하게 감소했다
C. 합성 대조군을 만들 수 없었다
D. 다른 주들도 동일한 효과를 보였다
정답: B
1988년 Proposition 99 시행 이후 캘리포니아의 담배 소비가 합성 캘리포니아보다 약 20갑/년 적었고, Placebo tests에서 다른 주들은 이런 효과를 보이지 않아 정책이 실제로 효과가 있었음을 입증했습니다.

Q5. 사전 매칭 품질이 나쁜 경우의 문제점은?

A. 계산 시간이 오래 걸린다
B. 처치 효과 추정이 편향될 수 있다
C. 가중치의 합이 1이 되지 않는다
D. Placebo test를 수행할 수 없다
정답: B
합성 대조군이 처치 전 기간에 처치 단위를 잘 재현하지 못하면 (사전 매칭 품질이 나쁘면), 처치 후 기간의 효과 추정도 신뢰하기 어렵고 편향될 가능성이 높습니다.

Q6. 외삽(Extrapolation) 문제가 발생하는 경우는?

A. 대조 단위가 너무 많은 경우
B. 처치 단위의 특성이 모든 대조 단위의 범위를 벗어난 경우
C. 처치 전 기간이 짧은 경우
D. 가중치가 균등한 경우
정답: B
처치 단위의 특성(예: GDP, 인구 등)이 모든 대조 단위의 범위를 벗어나면(convex hull 밖에 위치), 합성 대조군을 만들기 위해 외삽이 필요하며, 이는 추정의 신뢰성을 떨어뜨립니다.

Q7. Augmented Synthetic Control의 장점은?

A. 계산이 더 빠르다
B. 합성 대조군이 불완전할 때 회귀 조정을 통해 편향을 줄인다
C. 처치 전 데이터가 필요 없다
D. Placebo test가 필요 없다
정답: B
Augmented Synthetic Control은 전통적 합성 통제법에 회귀 조정(outcome regression)을 결합하여, 합성 대조군이 완벽하지 않을 때도 편향을 줄일 수 있습니다.
