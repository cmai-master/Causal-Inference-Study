고급 - Chapter 12

매개 분석 (Mediation Analysis)

인과 메커니즘을 분해하여 직접 효과와 간접 효과를 분리

🎯 매개 분석이란?

어떻게(how) 인과 효과가 발생하는가?
X → Y의 총 효과를 X → M → Y (간접)와 X → Y (직접)로 분해

전통적 접근: Baron & Kenny (1986)

Y = α1 + τX + ε1
M = α2 + aX + ε2
Y = α3 + τ'X + bM + ε3

간접 효과 = a × b
직접 효과 = τ'
총 효과 = τ

⚠️ 전통적 방법의 문제

  • 교란 가정이 매우 강함
  • M-Y 관계가 실험적으로 조작되지 않음
  • 비선형 모델에 일반화 어려움

현대적 접근: 인과 매개 분석

Imai et al. (2010), Pearl (2001)의 잠재적 결과 프레임워크

자연 직접 효과 (NDE):

E[Y(1, M(0)) - Y(0, M(0))]

매개변수를 대조군 수준으로 고정

자연 간접 효과 (NIE):

E[Y(1, M(1)) - Y(1, M(0))]

처치를 1로 고정하고 매개변수만 변화

순차적 무지성 가정

  1. (Y(t,m), M(t)) ⊥ T | X
  2. Y(t,m) ⊥ M | T, X
Python 
from causalinference import CausalModel

# 매개 분석
model = CausalModel(Y, treatment, mediator, covariates)
model.est_via_mediation()

print(f"Total Effect: {model.estimates['ate']:.3f}")
print(f"Direct Effect: {model.estimates['nde']:.3f}")
print(f"Indirect Effect: {model.estimates['nie']:.3f}")
