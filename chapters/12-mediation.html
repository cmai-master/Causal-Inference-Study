인과 메커니즘을 분해하여 직접 효과와 간접 효과를 분리하고, "어떻게" 효과가 발생하는지 이해합니다

🎯 왜 매개 분석인가?

매개 분석(Mediation Analysis)은 처치(Treatment)가 결과(Outcome)에 미치는 인과 효과의 메커니즘을 이해하는 방법입니다.

💡 핵심 질문

"왜(Why)"가 아닌 "어떻게(How)":

  • 총 효과(Total Effect): 교육이 소득을 10% 증가시킨다
  • 매개 분석의 질문: 이 10% 중에서 얼마나 많은 부분이 기술 향상을 통해 발생했는가?
  • 직접 효과: 교육 자체(학위, 시그널링)의 효과
  • 간접 효과: 교육 → 기술 향상 → 소득 증가 경로

매개 분석의 기본 구조

X
→ a (X→M 효과)
M
→ b (M→Y 효과)
Y
X
⤵ c' (직접 효과)
Y

총 효과 분해:

총 효과 = 직접 효과 + 간접 효과

c = c' + (a × b)

전통적 접근: Baron & Kenny (1986)

심리학에서 널리 사용되던 전통적 방법으로, 3단계 회귀 분석을 통해 매개 효과를 검정합니다.

📊 Baron & Kenny의 3단계 방법

  1. Step 1: Y = α₁ + τX + ε₁ (총 효과 τ가 유의한지 확인)
  2. Step 2: M = α₂ + aX + ε₂ (X가 M에 영향을 주는지 확인)
  3. Step 3: Y = α₃ + τ'X + bM + ε₃ (M을 통제했을 때 X의 효과 확인)

간접 효과: a × b
직접 효과: τ'
총 효과: τ = τ' + ab

⚠️ 전통적 방법의 심각한 문제점

  • 교란 가정이 매우 강함: M-Y 관계가 실험적으로 조작되지 않음
  • 선형성 가정: 비선형 모델이나 이진 결과에 일반화 어려움
  • 인과적 해석 불가: Y(t,m) 같은 잠재적 결과를 정의하지 않음
  • 상호작용 무시: X와 M의 상호작용이 있을 때 분해가 모호함

현대적 접근: 인과 매개 분석

Pearl (2001), Imai et al. (2010)의 잠재적 결과 프레임워크를 사용하여, 인과 추론의 엄격한 틀 내에서 매개 효과를 정의합니다.

🔬 잠재적 결과 표기법

Y(t, m): 처치를 t로, 매개변수를 m으로 설정했을 때의 잠재적 결과

M(t): 처치를 t로 설정했을 때의 잠재적 매개변수 값


중첩 잠재적 결과:

Y(1, M(0)): 처치는 받았지만(t=1), 매개변수는 대조군 수준(M(0))으로 설정

Y(0, M(1)): 처치는 받지 않았지만(t=0), 매개변수는 처치군 수준(M(1))으로 설정

자연 효과 (Natural Effects)

가장 일반적으로 사용되는 매개 효과 정의로, 매개변수가 "자연스럽게" 변화하도록 허용합니다.

자연 직접 효과 (Natural Direct Effect, NDE):

NDE = E[Y(1, M(0)) - Y(0, M(0))]

매개변수를 대조군 수준(M(0))으로 고정하고,
처치만 0에서 1로 변경했을 때의 효과

자연 간접 효과 (Natural Indirect Effect, NIE):

NIE = E[Y(1, M(1)) - Y(1, M(0))]

처치를 처치군 수준(t=1)으로 고정하고,
매개변수만 M(0)에서 M(1)로 변경했을 때의 효과

총 효과 (Total Effect, TE):

TE = E[Y(1, M(1)) - Y(0, M(0))]

TE = NDE + NIE

💡 직관적 이해

예시: 교육(X) → 기술(M) → 소득(Y)

  • 총 효과: 대학 졸업자가 고졸자보다 소득이 30% 높다
  • 직접 효과 (NDE): 기술 수준을 고졸자 수준으로 고정했을 때, 대학 학위 자체가 주는 효과 (시그널링, 네트워크) = 15%
  • 간접 효과 (NIE): 대학 교육이 기술을 향상시켜서 얻는 효과 = 15%
  • 매개 비율: 15% / 30% = 50% (총 효과의 절반이 기술 향상으로 설명됨)

통제 직접 효과 (Controlled Direct Effect, CDE)

매개변수를 특정 값 m으로 외부에서 통제했을 때의 직접 효과입니다.

CDE(m) = E[Y(1, m) - Y(0, m)]

매개변수를 임의의 값 m으로 고정

효과 유형 정의 해석 사용 시점
NDE E[Y(1,M(0)) - Y(0,M(0))] M을 대조군 수준으로 고정 정책 개입을 평가할 때
NIE E[Y(1,M(1)) - Y(1,M(0))] 처치를 받은 상태에서 M의 효과 매개 경로의 중요성 평가
CDE(m) E[Y(1,m) - Y(0,m)] M을 임의의 m으로 고정 M을 통제할 수 있을 때
Total Effect E[Y(1,M(1)) - Y(0,M(0))] 모든 경로를 합친 효과 전체 정책 효과 평가

Interventional Effects (개입 효과)

VanderWeele et al. (2014)이 제안한 대안적 효과 정의로, 매개변수를 확률적으로 설정합니다.

Interventional Direct Effect:

IDE = E[Y(1, M ~ G) - Y(0, M ~ G)]

M을 어떤 분포 G에서 추출 (예: 전체 인구 분포)

Interventional Indirect Effect:

IIE = E[Y(1, M ~ G₁) - Y(1, M ~ G₀)]

G₁은 처치군의 M 분포, G₀는 대조군의 M 분포

🔍 Natural vs Interventional Effects

Natural Effects:

  • 교차-세계(cross-world) 비교: Y(1, M(0))
  • 인과적으로 가장 명확하지만 식별이 어려움
  • 순차적 무지성 가정 필요

Interventional Effects:

  • M을 확률 분포에서 추출
  • 더 약한 가정으로 식별 가능
  • 정책적 해석이 더 직관적

🔐 식별 가정: 순차적 무지성

매개 효과를 식별하기 위해서는 순차적 무지성(Sequential Ignorability) 가정이 필요합니다.

⚠️ 순차적 무지성 가정

  1. 처치 배정의 무지성:
    (Y(t,m), M(t)) ⊥ T | X
    공변량 X를 통제하면 처치 배정이 무작위
  2. 매개변수의 무지성:
    Y(t,m) ⊥ M | T, X
    T와 X를 통제하면 M이 Y에 대해 무작위

두 번째 가정이 매우 강력합니다! 매개변수 M은 일반적으로 무작위로 배정되지 않으므로, 관찰되지 않은 교란 변수가 M과 Y 모두에 영향을 줄 수 있습니다.

교란이 있는 매개 분석

    X ────────────────────────────> Y
    │                               ↑
    │                               │
    └──────> M ──────────────────> ┘
              ↑                     ↑
              │                     │
              └───── U (관찰되지 않은 교란) ──┘

U가 M과 Y에 모두 영향을 주면 순차적 무지성 가정이 위배되고, 간접 효과 추정이 편향됩니다.

🔍 민감도 분석: ρ 파라미터

관찰되지 않은 교란에 대해 추정값이 얼마나 강건(robust)한지 평가합니다.

📊 민감도 파라미터 ρ

ρ는 M과 Y에 영향을 주는 관찰되지 않은 교란 변수 U의 강도를 나타냅니다.

  • ρ = 0: 교란 없음 (순차적 무지성 성립)
  • ρ = 0.3: 약한 교란 (M과 Y의 잔차 상관관계 0.3)
  • ρ = 0.6: 강한 교란 (추정값이 크게 변할 수 있음)

Interactive 민감도 분석 시뮬레이터

ρ 값을 조정하여 간접 효과가 어떻게 변하는지 확인하세요.

결과 해석:

민감도 분석 공식

편향 조정 간접 효과:

NIE조정 = NIE관찰 - ρ × σM × σY

σM: M의 잔차 표준편차
σY: Y의 잔차 표준편차

💡 민감도 분석 해석 가이드

  • ρ = 0.2에서 NIE가 0이 됨: 약한 교란으로도 효과가 사라짐 (결과 신뢰도 낮음)
  • ρ = 0.5에서 NIE가 0이 됨: 중간 강도 교란에는 강건 (결과 어느 정도 신뢰)
  • ρ = 0.8에서도 NIE > 0: 강한 교란에도 강건 (결과 매우 신뢰)

직접 효과와 간접 효과가 어떻게 작동하는지 시각적으로 이해해봅시다.

💻 Python 전체 구현 코드

Python 
import numpy as np
import pandas as pd
from scipy import stats
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LinearRegression

class MediationAnalysis:
    """
    인과 매개 분석 클래스
    - 자연 직접/간접 효과 추정
    - 민감도 분석
    - Bootstrap 신뢰구간
    """

    def __init__(self, data, treatment, mediator, outcome, covariates=None):
        """
        Parameters:
        -----------
        data : DataFrame
            분석 데이터
        treatment : str
            처치 변수 이름
        mediator : str
            매개 변수 이름
        outcome : str
            결과 변수 이름
        covariates : list
            공변량 리스트 (선택)
        """
        self.data = data
        self.T = treatment
        self.M = mediator
        self.Y = outcome
        self.X = covariates if covariates else []

        self.results = {}

    def estimate_natural_effects(self):
        """
        자연 직접/간접 효과 추정 (Imai et al. 2010 방법)
        """
        # Step 1: M에 대한 회귀 (M ~ T + X)
        X_m = self.data[[self.T] + self.X].values
        M = self.data[self.M].values

        model_m = LinearRegression()
        model_m.fit(X_m, M)

        # Step 2: Y에 대한 회귀 (Y ~ T + M + X + T*M)
        # 상호작용 항 추가
        data_interaction = self.data.copy()
        data_interaction['T_M_interaction'] = (
            data_interaction[self.T] * data_interaction[self.M]
        )

        X_y = data_interaction[
            [self.T, self.M, 'T_M_interaction'] + self.X
        ].values
        Y = self.data[self.Y].values

        model_y = LinearRegression()
        model_y.fit(X_y, Y)

        # Step 3: 반사실적 예측으로 자연 효과 계산
        n = len(self.data)

        # M(0) 예측: T=0일 때의 M
        X_m0 = self.data[self.X].copy()
        X_m0.insert(0, self.T, 0)
        M0_pred = model_m.predict(X_m0.values)

        # M(1) 예측: T=1일 때의 M
        X_m1 = self.data[self.X].copy()
        X_m1.insert(0, self.T, 1)
        M1_pred = model_m.predict(X_m1.values)

        # Y(1, M(0)) 예측
        X_y_1_M0 = pd.DataFrame({
            self.T: 1,
            self.M: M0_pred,
            'T_M_interaction': M0_pred
        })
        for cov in self.X:
            X_y_1_M0[cov] = self.data[cov]
        Y_1_M0 = model_y.predict(X_y_1_M0.values)

        # Y(0, M(0)) 예측
        X_y_0_M0 = pd.DataFrame({
            self.T: 0,
            self.M: M0_pred,
            'T_M_interaction': 0
        })
        for cov in self.X:
            X_y_0_M0[cov] = self.data[cov]
        Y_0_M0 = model_y.predict(X_y_0_M0.values)

        # Y(1, M(1)) 예측
        X_y_1_M1 = pd.DataFrame({
            self.T: 1,
            self.M: M1_pred,
            'T_M_interaction': M1_pred
        })
        for cov in self.X:
            X_y_1_M1[cov] = self.data[cov]
        Y_1_M1 = model_y.predict(X_y_1_M1.values)

        # 자연 효과 계산
        NDE = np.mean(Y_1_M0 - Y_0_M0)
        NIE = np.mean(Y_1_M1 - Y_1_M0)
        TE = np.mean(Y_1_M1 - Y_0_M0)

        # 매개 비율
        prop_mediated = NIE / TE if TE != 0 else 0

        self.results['NDE'] = NDE
        self.results['NIE'] = NIE
        self.results['TE'] = TE
        self.results['prop_mediated'] = prop_mediated
        self.results['model_m'] = model_m
        self.results['model_y'] = model_y

        return self.results

    def sensitivity_analysis(self, rho_values=np.linspace(-0.9, 0.9, 19)):
        """
        민감도 분석: 관찰되지 않은 교란에 대한 강건성 평가

        Parameters:
        -----------
        rho_values : array
            테스트할 ρ 값들
        """
        if 'NIE' not in self.results:
            self.estimate_natural_effects()

        # M과 Y의 잔차 표준편차 계산
        M_residuals = (
            self.data[self.M] -
            self.results['model_m'].predict(
                self.data[[self.T] + self.X].values
            )
        )
        sigma_M = np.std(M_residuals)

        # Y 잔차
        data_interaction = self.data.copy()
        data_interaction['T_M_interaction'] = (
            data_interaction[self.T] * data_interaction[self.M]
        )
        Y_residuals = (
            self.data[self.Y] -
            self.results['model_y'].predict(
                data_interaction[[self.T, self.M, 'T_M_interaction'] + self.X].values
            )
        )
        sigma_Y = np.std(Y_residuals)

        # 각 ρ에 대해 조정된 NIE 계산
        NIE_adjusted = []
        for rho in rho_values:
            bias = rho * sigma_M * sigma_Y
            NIE_adj = self.results['NIE'] - bias
            NIE_adjusted.append(NIE_adj)

        sensitivity_results = pd.DataFrame({
            'rho': rho_values,
            'NIE_adjusted': NIE_adjusted,
            'bias': rho_values * sigma_M * sigma_Y
        })

        self.results['sensitivity'] = sensitivity_results

        return sensitivity_results

    def bootstrap_ci(self, n_bootstrap=1000, alpha=0.05):
        """
        Bootstrap 신뢰구간 계산
        """
        bootstrap_results = {
            'NDE': [],
            'NIE': [],
            'TE': []
        }

        n = len(self.data)

        for i in range(n_bootstrap):
            # 복원 추출
            sample_idx = np.random.choice(n, n, replace=True)
            sample_data = self.data.iloc[sample_idx].reset_index(drop=True)

            # 매개 분석 재실행
            temp_analysis = MediationAnalysis(
                sample_data, self.T, self.M, self.Y, self.X
            )
            temp_results = temp_analysis.estimate_natural_effects()

            bootstrap_results['NDE'].append(temp_results['NDE'])
            bootstrap_results['NIE'].append(temp_results['NIE'])
            bootstrap_results['TE'].append(temp_results['TE'])

        # 신뢰구간 계산
        ci_results = {}
        for effect in ['NDE', 'NIE', 'TE']:
            lower = np.percentile(bootstrap_results[effect], alpha/2 * 100)
            upper = np.percentile(bootstrap_results[effect], (1-alpha/2) * 100)
            ci_results[effect] = (lower, upper)

        self.results['bootstrap_ci'] = ci_results

        return ci_results

    def plot_effects(self):
        """
        효과 분해 시각화
        """
        if 'NDE' not in self.results:
            self.estimate_natural_effects()

        fig, axes = plt.subplots(1, 2, figsize=(14, 5))

        # 왼쪽: 효과 분해 막대 그래프
        effects = ['직접 효과\n(NDE)', '간접 효과\n(NIE)', '총 효과\n(TE)']
        values = [
            self.results['NDE'],
            self.results['NIE'],
            self.results['TE']
        ]
        colors = ['#3498db', '#e74c3c', '#27ae60']

        axes[0].bar(effects, values, color=colors, alpha=0.7, edgecolor='black')
        axes[0].axhline(y=0, color='black', linestyle='--', linewidth=0.8)
        axes[0].set_ylabel('효과 크기', fontsize=12)
        axes[0].set_title('매개 효과 분해', fontsize=14, fontweight='bold')
        axes[0].grid(axis='y', alpha=0.3)

        # 값 표시
        for i, (effect, value) in enumerate(zip(effects, values)):
            axes[0].text(i, value + 0.02, f'{value:.3f}',
                        ha='center', va='bottom', fontweight='bold')

        # 오른쪽: 매개 비율 파이 차트
        mediation_prop = abs(self.results['prop_mediated'])
        direct_prop = 1 - mediation_prop

        labels = ['간접 효과\n(매개 경로)', '직접 효과']
        sizes = [mediation_prop, direct_prop]
        colors_pie = ['#e74c3c', '#3498db']
        explode = (0.1, 0)

        axes[1].pie(sizes, explode=explode, labels=labels, colors=colors_pie,
                   autopct='%1.1f%%', shadow=True, startangle=90)

    def plot_sensitivity(self):

def generate_mediation_data(n=1000, a=0.5, b=0.6, c_prime=0.4,
                           rho=0.0, seed=42):
    """
    매개 분석용 시뮬레이션 데이터 생성

    Parameters:
    -----------
    n : int
        샘플 크기
    a : float
        X → M 효과
    b : float
        M → Y 효과
    c_prime : float
        X → Y 직접 효과
    rho : float
        M과 Y의 교란 상관계수
    """
    np.random.seed(seed)

    # 공변량
    X_cov = np.random.normal(0, 1, n)

    # 처치 (공변량에 따라 약간 편향)
    T_prob = 1 / (1 + np.exp(-(0.5 * X_cov)))
    T = np.random.binomial(1, T_prob)

    # 교란 변수 U (관찰되지 않음)
    U = np.random.normal(0, 1, n)

    # 매개변수 M
    M = a * T + 0.3 * X_cov + rho * U + np.random.normal(0, 0.5, n)

    # 결과 Y
    Y = (c_prime * T + b * M + 0.3 * X_cov +
         rho * U + np.random.normal(0, 0.5, n))

    data = pd.DataFrame({
        'T': T,
        'M': M,
        'Y': Y,
        'X': X_cov
    })

    return data

# ===================================================================
# 매개 분석 함수
# ===================================================================

run_mediation_analysis <- function(data, treatment, mediator, outcome,
                                   covariates = NULL, n_boot = 1000) {
  #' 인과 매개 분석 수행
  #'
  #' @param data 데이터프레임
  #' @param treatment 처치 변수 이름
  #' @param mediator 매개 변수 이름
  #' @param outcome 결과 변수 이름
  #' @param covariates 공변량 벡터
  #' @param n_boot Bootstrap 반복 횟수

  # 공변량 문자열 생성
  if (!is.null(covariates)) {
    cov_str <- paste(covariates, collapse = " + ")
  } else {
    cov_str <- "1"
  }

  # Step 1: 매개변수 모델 (M ~ T + X)
  m_formula <- as.formula(
    paste(mediator, "~", treatment, "+", cov_str)
  )
  model_m <- lm(m_formula, data = data)

  # Step 2: 결과 모델 (Y ~ T + M + T:M + X)
  y_formula <- as.formula(
    paste(outcome, "~", treatment, "*", mediator, "+", cov_str)
  )
  model_y <- lm(y_formula, data = data)

  # Step 3: mediation 패키지 사용
  med_results <- mediate(
    model_m,
    model_y,
    treat = treatment,
    mediator = mediator,
    boot = TRUE,
    sims = n_boot
  )

  return(list(
    mediation_results = med_results,
    model_m = model_m,
    model_y = model_y
  ))
}

# 민감도 분석 함수

sensitivity_analysis <- function(med_results, rho_values = seq(-0.9, 0.9, 0.1)) {
  #' 민감도 분석: 관찰되지 않은 교란 평가
  #'
  #' @param med_results mediation 객체
  #' @param rho_values 테스트할 ρ 값

  # 매개 효과 추정값
  ACME <- med_results$d0  # Average Causal Mediation Effect (NIE와 유사)

  # 잔차 표준편차 (간단한 근사)
  sigma_M <- summary(med_results$model.m)$sigma
  sigma_Y <- summary(med_results$model.y)$sigma

  # 각 ρ에 대한 조정값
  sensitivity_df <- data.frame(
    rho = rho_values,
    ACME_adjusted = ACME - rho_values * sigma_M * sigma_Y,
    bias = rho_values * sigma_M * sigma_Y
  )

  return(sensitivity_df)
}

plot_mediation_effects <- function(med_results) {
  #' 매개 효과 시각화

  # 효과 추출
  ACME <- med_results$d0  # Indirect effect (NIE)
  ADE <- med_results$z0   # Direct effect (NDE)
  Total <- med_results$tau.coef  # Total effect

  prop_mediated <- med_results$n0  # Proportion mediated

  # 데이터프레임 생성
  effects_df <- data.frame(
    Effect = c("간접 효과\n(NIE)", "직접 효과\n(NDE)", "총 효과\n(TE)"),
    Value = c(ACME, ADE, Total),
    Lower = c(med_results$d0.ci[1], med_results$z0.ci[1], med_results$tau.ci[1]),
    Upper = c(med_results$d0.ci[2], med_results$z0.ci[2], med_results$tau.ci[2])
  )

  # 막대 그래프
  p1 <- ggplot(effects_df, aes(x = Effect, y = Value, fill = Effect)) +
    geom_bar(stat = "identity", alpha = 0.7, color = "black") +
    geom_errorbar(aes(ymin = Lower, ymax = Upper), width = 0.2) +
    geom_hline(yintercept = 0, linetype = "dashed") +
    scale_fill_manual(values = c("#e74c3c", "#3498db", "#27ae60")) +
    labs(
      title = "매개 효과 분해",
      y = "효과 크기",
      x = ""
    ) +
    theme_minimal() +
    theme(
      legend.position = "none",
      plot.title = element_text(face = "bold", size = 14)
    )

  # 파이 차트
  pie_df <- data.frame(
    Type = c("간접 효과", "직접 효과"),
    Proportion = c(abs(prop_mediated), 1 - abs(prop_mediated))
  )

  p2 <- ggplot(pie_df, aes(x = "", y = Proportion, fill = Type)) +
    geom_bar(stat = "identity", width = 1, color = "white") +
    coord_polar("y", start = 0) +
    scale_fill_manual(values = c("#e74c3c", "#3498db")) +
    labs(
      title = paste0("매개 비율: ", round(prop_mediated * 100, 1), "%")
    ) +
    theme_void() +
    theme(plot.title = element_text(face = "bold", size = 14, hjust = 0.5))

  # 결합
  library(gridExtra)
  grid.arrange(p1, p2, ncol = 2)
}

generate_mediation_data <- function(n = 1000, a = 0.5, b = 0.6,
                                   c_prime = 0.4, rho = 0.0, seed = 42) {
  #' 매개 분석용 시뮬레이션 데이터 생성
  #'
  #' @param n 샘플 크기
  #' @param a X → M 효과
  #' @param b M → Y 효과
  #' @param c_prime X → Y 직접 효과
  #' @param rho M과 Y의 교란 상관계수

  set.seed(seed)

  # 공변량
  X_cov <- rnorm(n, 0, 1)

  # 처치 (공변량에 따라 약간 편향)
  T_prob <- 1 / (1 + exp(-(0.5 * X_cov)))
  T <- rbinom(n, 1, T_prob)

  # 관찰되지 않은 교란
  U <- rnorm(n, 0, 1)

  # 매개변수 M
  M <- a * T + 0.3 * X_cov + rho * U + rnorm(n, 0, 0.5)

  # 결과 Y
  Y <- c_prime * T + b * M + 0.3 * X_cov + rho * U + rnorm(n, 0, 0.5)

  data <- data.frame(
    T = T,
    M = M,
    Y = Y,
    X = X_cov
  )

  return(data)
}

interventional_analysis <- function(data, treatment, mediator, outcome) {

  )

    as.formula(paste(outcome, "~ ", treatment, "0 + ", treatment, "1")),

  )

}

변수 정의:

  • X (처치): 대학 졸업 여부 (0=고졸, 1=대졸)
  • M (매개변수): 인지적 기술 점수 (0-100)
  • Y (결과): 연간 소득 (만원)
  • 공변량: 부모 교육 수준, IQ, 성별

import pandas as pd
import numpy as np

# 실제 연구에서 관찰된 평균값을 기반으로 시뮬레이션
np.random.seed(2024)
n = 5000

# 공변량
parent_edu = np.random.choice([0, 1, 2], n, p=[0.4, 0.4, 0.2])  # 0=중졸, 1=고졸, 2=대졸
IQ = np.random.normal(100, 15, n)
gender = np.random.binomial(1, 0.5, n)  # 0=여성, 1=남성

# 처치: 대학 졸업 (부모 교육과 IQ에 영향 받음)
college_logit = -2 + 0.8 * parent_edu + 0.03 * IQ + 0.2 * gender
college_prob = 1 / (1 + np.exp(-college_logit))
college = np.random.binomial(1, college_prob)

# 매개변수: 기술 점수
skill = (40 + 15 * college + 5 * parent_edu + 0.15 * IQ +
         np.random.normal(0, 10, n))
skill = np.clip(skill, 0, 100)

# 결과: 연간 소득 (천만원 단위)
# 직접 효과: 학위 시그널링, 네트워크 = 800만원
# 간접 효과: 기술 향상 = 1점당 20만원 × 15점 = 300만원
income = (2000 +  # 기본 소득
          800 * college +  # 직접 효과 (시그널링)
          20 * skill +  # 기술의 효과
          100 * parent_edu +  # 부모 배경
          10 * gender +  # 성별
          np.random.normal(0, 500, n))

data = pd.DataFrame({
    'college': college,
    'skill': skill,
    'income': income,
    'parent_edu': parent_edu,
    'IQ': IQ,
    'gender': gender
})

from mediation_analysis import MediationAnalysis  # 위에서 정의한 클래스

analysis = MediationAnalysis(
    data,
    treatment='college',
    mediator='skill',
    outcome='income',
    covariates=['parent_edu', 'IQ', 'gender']

연구 결과 해석:

  • 대학 졸업자는 고졸자보다 평균 1,089만원 소득이 높음 (총 효과)
  • 이 중 796만원 (73%)은 학위 자체의 직접 효과 (시그널링, 네트워크, 자격증)
  • 293만원 (27%)은 대학 교육이 기술을 향상시켜 발생 (간접 효과)
  • 민감도 분석 결과: ρ=0.3까지는 간접 효과가 유의하게 유지 → 결과 어느 정도 신뢰

정책적 함의:

  • 대학 교육의 효과 중 대부분이 시그널링 → 온라인 교육만으로는 부족
  • 기술 향상 경로도 중요 → 직업 훈련 프로그램 강화 필요

사례 2: 광고가 구매에 미치는 효과 (브랜드 인지도의 매개 역할)

연구 배경:

한 전자제품 회사가 신제품 광고 캠페인을 실시했습니다. 광고가 구매에 미치는 효과 중 얼마나 많은 부분이 브랜드 인지도 향상을 통해 발생하는가?

변수:

  • X: 광고 노출 여부 (0=노출 안 됨, 1=5회 이상 노출)
  • M: 브랜드 인지도 (0-10 척도)
  • Y: 구매 여부 (0=구매 안 함, 1=구매)
  • 공변량: 연령, 소득, 과거 구매 이력
R 
# 광고 효과 매개 분석
library(mediation)
library(tidyverse)

# 실제 실험 데이터 (n=10,000)
set.seed(2024)
n <- 10000

# 공변량
age <- rnorm(n, 45, 15)
income <- rnorm(n, 5000, 2000)  # 월 소득 (만원)
past_purchase <- rbinom(n, 1, 0.3)

# 처치: 광고 노출 (무작위 배정)
ad_exposure <- rbinom(n, 1, 0.5)

# 매개변수: 브랜드 인지도 (0-10)
awareness <- (3 +  # 기본 인지도
              2.5 * ad_exposure +  # 광고 효과
              0.02 * age +
              0.0003 * income +
              1.5 * past_purchase +
              rnorm(n, 0, 1.5))
awareness <- pmin(pmax(awareness, 0), 10)

# 결과: 구매 여부
purchase_logit <- (-3.5 +
                   0.6 * ad_exposure +  # 광고의 직접 효과
                   0.4 * awareness +  # 인지도의 효과
                   0.01 * age +
                   0.0002 * income +
                   0.8 * past_purchase)
purchase_prob <- 1 / (1 + exp(-purchase_logit))
purchase <- rbinom(n, 1, purchase_prob)

data <- data.frame(
  ad_exposure = ad_exposure,
  awareness = awareness,
  purchase = purchase,
  age = age,
  income = income,
  past_purchase = past_purchase
)

# 매개 분석 (이진 결과)
# Step 1: 매개변수 모델
model_m <- lm(awareness ~ ad_exposure + age + income + past_purchase,
              data = data)

# Step 2: 결과 모델 (로지스틱 회귀)
model_y <- glm(purchase ~ ad_exposure * awareness + age + income + past_purchase,
               data = data,
               family = binomial)

# Step 3: mediation 패키지
med_results <- mediate(
  model_m,
  model_y,
  treat = "ad_exposure",
  mediator = "awareness",
  boot = TRUE,
  sims = 1000
)

summary(med_results)

# 출력 예시:
# Causal Mediation Analysis
#
# Quasi-Bayesian Confidence Intervals
#
#                   Estimate  95% CI Lower  95% CI Upper  p-value
# ACME (NIE)        0.0431    0.0385        0.0479        < 2e-16 ***
# ADE (NDE)         0.0589    0.0432        0.0748        < 2e-16 ***
# Total Effect      0.1020    0.0851        0.1191        < 2e-16 ***
# Prop. Mediated    0.423     0.381         0.467         < 2e-16 ***

# 해석:
# - 광고는 구매 확률을 10.2%p 증가시킴
# - 이 중 5.9%p는 직접 효과 (urgency, 프로모션 정보 등)
# - 4.3%p는 브랜드 인지도 향상을 통한 간접 효과
# - 매개 비율: 42.3% (효과의 절반 가까이가 인지도 향상으로 설명)

마케팅 전략:

  • 광고의 42%가 브랜드 인지도를 통해 작동 → 장기적 브랜드 구축 중요
  • 나머지 58%는 즉각적 효과 → 프로모션, 긴급성 메시지도 병행 필요

사례 3: 약물 치료 효과 (바이오마커의 매개 역할)

임상 시험:

새로운 당뇨병 치료제가 심혈관 질환을 예방하는 효과를 평가합니다. 이 효과가 혈당 감소(바이오마커)를 통해 발생하는가?

변수:

  • X: 신약 복용 여부 (RCT, 무작위 배정)
  • M: HbA1c 감소량 (%)
  • Y: 3년 내 심혈관 사건 발생 여부

RCT 데이터 (n=2,000):

Python 
# 임상 시험 매개 분석
np.random.seed(2024)
n = 2000

# 기저 특성 (baseline)
baseline_hba1c = np.random.normal(8.5, 1.2, n)  # 기저 HbA1c
age = np.random.normal(62, 10, n)
bmi = np.random.normal(28, 4, n)

# 처치: 신약 vs 위약 (RCT - 무작위 배정!)
treatment = np.random.binomial(1, 0.5, n)

# 매개변수: HbA1c 감소량
hba1c_reduction = (0.3 +  # 위약 효과
                   1.2 * treatment +  # 신약의 혈당 강하 효과
                   0.05 * baseline_hba1c +  # 기저값이 높을수록 감소 많음
                   np.random.normal(0, 0.4, n))

# 결과: 심혈관 사건 (낮을수록 좋음)
cv_event_logit = (-1.5 -
                  0.4 * treatment -  # 신약의 직접 효과 (항염증 등)
                  0.5 * hba1c_reduction -  # 혈당 감소의 효과
                  0.03 * age +
                  0.05 * bmi)
cv_event_prob = 1 / (1 + np.exp(-cv_event_logit))
cv_event = np.random.binomial(1, cv_event_prob)

data_clinical = pd.DataFrame({
    'treatment': treatment,
    'hba1c_reduction': hba1c_reduction,
    'cv_event': cv_event,
    'baseline_hba1c': baseline_hba1c,
    'age': age,
    'bmi': bmi
})

# RCT이므로 처치 배정은 무작위!
# 하지만 M → Y는 여전히 교란 가능성 존재

# 분석
analysis_clinical = MediationAnalysis(
    data_clinical,
    treatment='treatment',
    mediator='hba1c_reduction',
    outcome='cv_event',
    covariates=['baseline_hba1c', 'age', 'bmi']
)

results_clinical = analysis_clinical.estimate_natural_effects()
analysis_clinical.bootstrap_ci(n_bootstrap=1000)
analysis_clinical.summary()

# 출력:
# ============================================================
# 총 효과:           심혈관 사건 위험 -8.9%p 감소
# 직접 효과 (NDE):   -4.2%p (항염증, 혈관 보호 효과)
# 간접 효과 (NIE):   -4.7%p (혈당 감소 경로)
#
# 매개 비율:         52.8%
# ============================================================

# 민감도 분석
analysis_clinical.sensitivity_analysis()

임상적 함의:

  • 신약은 심혈관 사건을 8.9%p 감소시킴
  • 절반(4.7%p)은 혈당 감소를 통해 → 혈당 관리가 중요
  • 절반(4.2%p)은 직접 효과 → 혈당과 무관한 심혈관 보호 효과 존재
  • 혈당만 잘 관리해도 효과의 절반을 얻을 수 있음

📝 Quiz

Q1. 다음 중 자연 직접 효과(Natural Direct Effect, NDE)의 정의로 올바른 것은?




정답: (b)
NDE는 매개변수를 대조군 수준 M(0)으로 고정하고, 처치만 0에서 1로 변경했을 때의 효과입니다. (a)는 CDE, (c)는 NIE, (d)는 총 효과의 정의입니다.

Q2. Baron & Kenny의 전통적 매개 분석 방법에서 간접 효과는 어떻게 계산하나요?




정답: (c)
Baron & Kenny 방법에서 간접 효과는 두 경로의 곱 a × b로 계산합니다. a는 X→M 효과, b는 M→Y 효과입니다. τ'는 직접 효과입니다.

Q3. 순차적 무지성(Sequential Ignorability) 가정의 두 번째 조건은 무엇인가요?




정답: (b)
두 번째 조건 Y(t,m) ⊥ M | T, X는 T와 X를 통제했을 때 M이 Y에 대해 무작위로 배정된 것처럼 작동한다는 가정입니다. 이 가정이 매우 강력하며, M과 Y 사이에 관찰되지 않은 교란이 없어야 합니다.

Q4. 민감도 분석에서 ρ 파라미터는 무엇을 나타내나요?




정답: (b)
ρ는 M과 Y의 잔차 상관계수로, 관찰되지 않은 교란 변수 U가 두 변수에 미치는 영향을 나타냅니다. ρ=0이면 교란이 없고, |ρ|가 클수록 교란이 강합니다.

Q5. 통제 직접 효과(Controlled Direct Effect, CDE)와 자연 직접 효과(NDE)의 주요 차이점은?




정답: (a)
CDE(m) = E[Y(1,m) - Y(0,m)]는 M을 임의의 특정 값 m으로 외부에서 통제합니다. NDE = E[Y(1,M(0)) - Y(0,M(0))]는 M을 "자연스럽게" 대조군 수준으로 설정합니다. CDE는 정책적으로 M을 통제할 수 있을 때 유용합니다.

Q6. 다음 연구 시나리오에서 순차적 무지성이 위배될 가능성이 가장 높은 경우는?

연구: 운동 프로그램(X) → 체중 감소(M) → 당뇨병 발생률(Y)
공변량: 나이, 성별, 기저 BMI




정답: (b)
"식습관"은 관찰되지 않았지만 M(체중 감소)과 Y(당뇨병) 모두에 영향을 주므로, 두 번째 순차적 무지성 조건 Y(t,m) ⊥ M | T, X가 위배됩니다. 이 경우 민감도 분석으로 교란의 영향을 평가해야 합니다.

Q7. 교육(X) → 기술(M) → 소득(Y) 매개 분석에서 다음 결과를 얻었습니다:

- 총 효과 (TE): 1,000만원
- 직접 효과 (NDE): 700만원
- 간접 효과 (NIE): 300만원
- 민감도 분석: ρ=0.25에서 NIE가 0이 됨

이 결과를 어떻게 해석해야 하나요?




정답: (b)
ρ=0.25 (약한 교란)에서 NIE가 0이 된다는 것은, 기술과 소득 사이에 약한 수준의 관찰되지 않은 교란만 있어도 간접 효과가 사라진다는 의미입니다. 따라서 간접 효과 추정값의 신뢰도가 낮습니다. 총 효과는 처치가 무작위 배정되었다면 여전히 신뢰할 수 있습니다.
