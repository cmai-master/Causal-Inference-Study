중급 - Chapter 9

회귀 불연속 설계 (Regression Discontinuity Design)

임계값 기반 처치 배정의 불연속성을 활용한 준실험 설계

🎯 RDD의 핵심 아이디어

처치 배정이 연속 변수(running variable)의 임계값(cutoff)에 의해 결정될 때, 임계값 근처에서 처치군과 대조군은 유사합니다 (국소 무작위화).

Sharp RDD vs Fuzzy RDD

Sharp RDD

임계값에서 처치 확률이 0에서 1로 점프

T = 1{X ≥ c}

Fuzzy RDD

임계값에서 처치 확률이 불연속적으로 변화

P(T=1|X) 불연속

타당성 가정

  • 연속성: 잠재적 결과가 임계값에서 연속
  • 조작 불가: Running variable 조작 없음
  • 국소성: 임계값 근처에서만 유효

추정 방법

Python 
from rdd import rdd

# Sharp RDD
result = rdd.truncated_linear_rdd(
    data['Y'],
    data['running_var'],
    cutoff=0,
    bandwidth='optimal'
)

print(f"Treatment Effect: {result.est[0]:.3f}")
print(f"SE: {result.se[0]:.3f}")

대표 연구: Lee et al. (2008) - 현직 효과

선거에서 간신히 이긴 후보 vs 간신히 진 후보
Running variable: 득표율 차이
Cutoff: 0%
결과: 현직 의원의 재선 확률 증가
