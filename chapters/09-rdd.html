🎯 RDD란 무엇인가?

회귀 불연속 설계(Regression Discontinuity Design, RDD)는 처치 배정이 연속 변수의 임계값에 의해 결정되는 상황에서 인과 효과를 추정하는 준실험 설계(Quasi-experimental design) 방법입니다.

💡 핵심 아이디어

어떤 점수나 지표가 특정 임계값(cutoff)을 넘으면 처치를 받고, 넘지 못하면 받지 못하는 상황을 생각해보세요.

임계값 바로 위와 바로 아래의 사람들은 매우 유사합니다!

예: 시험 점수 70점 이상이면 장학금, 69점이면 못 받는 경우 → 70점과 69점 학생은 거의 같은데 장학금 유무만 다릅니다.

실생활 예시

🎓 장학금 배정

Running variable: 성적 (GPA)

Cutoff: 3.5

처치: 장학금 수령

결과: 향후 학업 성과

GPA 3.49와 3.51 학생은 거의 동일하지만 장학금 수령 여부만 다름

🍺 음주 연령 제한

Running variable: 나이

Cutoff: 만 19세 (한국)

처치: 합법적 음주 가능

결과: 건강, 사고율

18세 364일과 19세 0일은 거의 같은 사람

🏫 학급 규모 규정

Running variable: 학생 수

Cutoff: 40명

처치: 학급 분반 (소규모)

결과: 학업 성취도

🔍 Sharp RDD vs Fuzzy RDD

1. Sharp RDD (날카로운 RDD)

임계값에서 처치 확률이 0에서 1로 완벽하게 점프합니다.

처치 배정 규칙:

Ti = 1{Xi ≥ c}

Xi ≥ c 이면 무조건 처치 (T=1)
Xi < c 이면 무조건 미처치 (T=0)

Sharp RDD 예시:

  • 시험 점수 70점 이상 → 무조건 합격
  • 만 19세 이상 → 법적으로 음주 가능
  • 소득 100만원 이하 → 자동으로 복지 혜택

Sharp RDD 추정량

τRDD = limx↓c E[Y|X=x] - limx↑c E[Y|X=x]

임계값 바로 오른쪽 평균 - 임계값 바로 왼쪽 평균

2. Fuzzy RDD (흐릿한 RDD)

임계값에서 처치 확률이 불연속적으로 변화하지만, 0→1로 완벽하게 점프하지는 않음

처치 배정 규칙:

P(Ti=1 | Xi ≥ c) > P(Ti=1 | Xi < c)

임계값 위에서 처치 확률이 더 높지만, 100%는 아님

Fuzzy RDD 예시:

  • 대학 입학 기준: 점수가 높아도 일부는 등록 안 함 (컴플라이언스 불완전)
  • 의료 서비스 자격: 소득 기준 충족해도 신청 안 하는 사람 존재
  • 군 복무: 신체검사 기준 통과해도 면제받는 경우 존재

Fuzzy RDD 추정량 (IV와 유사)

τFuzzy = [limx↓c E[Y|X=x] - limx↑c E[Y|X=x]] / [limx↓c E[T|X=x] - limx↑c E[T|X=x]]

결과의 불연속 / 처치의 불연속 = LATE (Local Average Treatment Effect)

비교표

특징 Sharp RDD Fuzzy RDD
처치 배정 결정론적 (Deterministic) 확률적 (Probabilistic)
임계값에서 처치 확률 변화 0 → 1 (100% 점프) p1 → p2 (불완전 점프)
추정 방법 직접 회귀 도구변수 (2SLS)
추정하는 효과 ATE (at cutoff) LATE (Compliers)
예시 법정 연령 제한 대학 입학 자격

🔑 RDD의 타당성 가정

RDD가 인과 효과를 정확히 추정하려면 다음 가정들이 만족되어야 합니다.

1. 연속성 가정 (Continuity Assumption)

잠재적 결과 Y(0)과 Y(1)이 임계값에서 연속이어야 합니다.

limx↓c E[Y(0)|X=x] = limx↑c E[Y(0)|X=x]

limx↓c E[Y(1)|X=x] = limx↑c E[Y(1)|X=x]

즉, 처치가 없었다면 결과가 임계값에서 매끄럽게 이어져야 합니다.

2. 조작 불가 가정 (No Manipulation)

개인이 Running variable을 정밀하게 조작할 수 없어야 합니다.

위배 사례:

  • 학생이 정확히 장학금 기준을 맞추기 위해 점수 조작
  • 기업이 보조금 기준을 피하기 위해 매출 조정
  • 정치인이 선거 득표를 조작

검증 방법: McCrary 밀도 테스트

임계값 근처에서 Running variable의 밀도 함수가 연속적인지 검사합니다. 조작이 있다면 임계값 바로 위 또는 아래에 관측치가 비정상적으로 많이 몰릴 것입니다.

Python 
from rddensity import rddensity

# McCrary 밀도 테스트
density_test = rddensity(data['running_var'], c=0)
print(f"Test statistic: {density_test.test['t_jk']}")
print(f"P-value: {density_test.test['p_jk']}")

3. 국소성 (Local Randomization)

임계값 근처에서는 처치 배정이 사실상 무작위입니다.

예: 시험 70점과 69점은 우연에 의한 차이일 뿐, 두 그룹의 다른 특성들(지능, 노력, 배경)은 유사할 것입니다.

검증 방법: Balance Test (균형 검정)

사전 결정된 공변량(pre-determined covariates)이 임계값에서 불연속을 보이는지 확인합니다. 만약 불연속이 있다면 국소 무작위화 가정이 의심됩니다.

R 
# 공변량 균형 검정
rdplot(data$age, data$running_var, c=0,
       title="Age Balance Test",
       x.label="Running Variable",
       y.label="Age")

📐 RDD 추정 방법

1. 로컬 선형 회귀 (Local Linear Regression)

가장 널리 사용되는 방법으로, 임계값 근처 데이터만 사용하여 양쪽에서 각각 선형 회귀를 실행합니다.

회귀 모형:

Yi = α + τDi + β1(Xi - c) + β2Di(Xi - c) + εi

Di = 1{Xi ≥ c}: 처치 지시자
(Xi - c): 임계값으로부터의 거리
τ: RDD 추정 효과 (관심 파라미터)

2. 대역폭 선택 (Bandwidth Selection)

대역폭(h)은 임계값으로부터 얼마나 멀리까지 데이터를 사용할지 결정합니다.

좁은 대역폭

장점:

  • 편향(Bias) 감소
  • 국소 무작위화 가정 더 타당

단점:

  • 분산(Variance) 증가
  • 샘플 크기 감소

넓은 대역폭

장점:

  • 분산(Variance) 감소
  • 더 많은 데이터 사용

단점:

  • 편향(Bias) 증가
  • 국소성 가정 위배 가능

💡 최적 대역폭

Imbens-Kalyanaraman (2012) 또는 Calonico-Cattaneo-Titiunik (2014) 방법 사용

편향과 분산의 균형(MSE 최소화)을 자동으로 찾아줍니다.

3. 다항식 차수 선택

임계값 양쪽에서 어느 정도 차수의 다항식을 사용할지 결정합니다.

  • 1차 (선형): 가장 일반적, Gelman & Imbens (2019) 권장
  • 2차 이상: 비선형 관계가 명확한 경우만 사용

⚠️ 고차 다항식의 위험

Gelman & Imbens (2019)는 3차 이상 다항식 사용을 권장하지 않습니다.

이유: 임계값에서 멀리 떨어진 데이터에 과도하게 영향받고, 추정량이 불안정해집니다.

💻 Python 구현: rdrobust

rdrobust 패키지는 RDD 분석의 표준 도구입니다 (Calonico, Cattaneo, Titiunik).

Python 
# 설치
pip install rdrobust

import numpy as np
import pandas as pd
from rdrobust import rdrobust, rdbwselect, rdplot

# 데이터 생성 (예시)
np.random.seed(123)
n = 1000
X = np.random.uniform(-50, 50, n)  # Running variable
T = (X >= 0).astype(int)            # Treatment (cutoff at 0)

# 잠재적 결과
Y0 = 50 + 0.5*X + np.random.normal(0, 10, n)
Y1 = Y0 + 10  # Treatment effect = 10

# 관찰된 결과
Y = T * Y1 + (1-T) * Y0

# DataFrame 생성
data = pd.DataFrame({'Y': Y, 'X': X, 'T': T})

# ==============================
# Sharp RDD 추정
# ==============================

# 1. 최적 대역폭 자동 선택
result = rdrobust(Y, X, c=0)
print(result)

# 주요 결과:
# - Coef: RDD 추정 효과
# - Bias-corrected robust 95% CI
# - Bandwidth (h): 최적 대역폭

# 2. 대역폭 수동 지정
result_manual = rdrobust(Y, X, c=0, h=15)

# 3. 시각화
rdplot_result = rdplot(Y, X, c=0,
                       title='Sharp RDD Example',
                       x_label='Running Variable',
                       y_label='Outcome')

# ==============================
# Fuzzy RDD 추정
# ==============================

# Compliance가 불완전한 경우 (80%)
T_fuzzy = np.where(X >= 0,
                   np.random.binomial(1, 0.8, n),
                   np.random.binomial(1, 0.2, n))

Y_fuzzy = T_fuzzy * Y1 + (1-T_fuzzy) * Y0

# Fuzzy RDD: fuzzy 옵션 사용
result_fuzzy = rdrobust(Y_fuzzy, X, c=0,
                        fuzzy=T_fuzzy)
print(result_fuzzy)

# ==============================
# 강건성 검증
# ==============================

# 1. 다양한 대역폭으로 검증
bandwidths = [10, 15, 20, 25, 30]
estimates = []

for h in bandwidths:
    res = rdrobust(Y, X, c=0, h=h)
    estimates.append({
        'bandwidth': h,
        'coef': res.coef[0],
        'se': res.se[0],
        'ci_lower': res.ci[0, 0],
        'ci_upper': res.ci[1, 0]
    })

sensitivity_df = pd.DataFrame(estimates)
print(sensitivity_df)

# 2. Placebo cutoff 테스트
# 가짜 임계값에서는 효과가 없어야 함
placebo_cutoffs = [-20, -10, 10, 20]

for c_placebo in placebo_cutoffs:
    res = rdrobust(Y, X, c=c_placebo)
    print(f"Placebo cutoff {c_placebo}: {res.coef[0]:.3f} (p={res.pv[0]:.3f})")

# ==============================
# 공변량 균형 검정
# ==============================

# 사전 결정된 변수가 임계값에서 불연속을 보이는지 확인
age = 30 + 0.1*X + np.random.normal(0, 5, n)

balance_test = rdrobust(age, X, c=0)
print("Age balance test:")
print(f"Discontinuity: {balance_test.coef[0]:.3f}")
print(f"P-value: {balance_test.pv[0]:.3f}")
# P-value가 크면 균형 만족 (좋음)

R 
# 설치
install.packages("rdrobust")

library(rdrobust)
library(ggplot2)

# 데이터 생성
set.seed(123)
n <- 1000
X <- runif(n, -50, 50)
T <- as.numeric(X >= 0)

Y0 <- 50 + 0.5*X + rnorm(n, 0, 10)
Y1 <- Y0 + 10

Y <- T * Y1 + (1-T) * Y0

data <- data.frame(Y=Y, X=X, T=T)

# ==============================
# Sharp RDD
# ==============================

# 기본 추정
rdd_result <- rdrobust(Y, X, c=0)
summary(rdd_result)

# 시각화
rdplot(Y, X, c=0,
       title="Sharp RDD",
       x.label="Running Variable",
       y.label="Outcome",
       ci=95)

# 대역폭 선택 알고리즘 비교
bw_ik <- rdbwselect(Y, X, c=0, bwselect="mserd")  # IK
bw_cct <- rdbwselect(Y, X, c=0, bwselect="msetwo") # CCT

summary(bw_ik)
summary(bw_cct)

# ==============================
# Fuzzy RDD
# ==============================

# Compliance 80%
T_fuzzy <- ifelse(X >= 0,
                  rbinom(n, 1, 0.8),
                  rbinom(n, 1, 0.2))

Y_fuzzy <- T_fuzzy * Y1 + (1-T_fuzzy) * Y0

rdd_fuzzy <- rdrobust(Y_fuzzy, X, fuzzy=T_fuzzy, c=0)
summary(rdd_fuzzy)

# ==============================
# McCrary 밀도 테스트
# ==============================

library(rdd)
DCdensity(X, cutpoint=0)

# ==============================
# 공변량 균형
# ==============================

age <- 30 + 0.1*X + rnorm(n, 0, 5)

rdplot(age, X, c=0,
       title="Covariate Balance: Age",
       x.label="Running Variable",
       y.label="Age")

balance <- rdrobust(age, X, c=0)
summary(balance)

# ==============================
# 강건성 검증
# ==============================

# 1. 다양한 대역폭
bandwidths <- c(10, 15, 20, 25, 30)
results <- data.frame()

for(h in bandwidths) {
  res <- rdrobust(Y, X, c=0, h=h)
  results <- rbind(results, data.frame(
    bandwidth = h,
    coef = res$coef[1],
    se = res$se[1],
    ci_lower = res$ci[1,1],
    ci_upper = res$ci[2,1]
  ))
}

# 시각화
ggplot(results, aes(x=bandwidth, y=coef)) +
  geom_point() +
  geom_errorbar(aes(ymin=ci_lower, ymax=ci_upper), width=1) +
  geom_hline(yintercept=10, linetype="dashed", color="red") +
  labs(title="Sensitivity to Bandwidth Choice",
       x="Bandwidth", y="Treatment Effect Estimate") +
  theme_minimal()

# 2. Donut hole (임계값 바로 근처 제외)
rdd_donut <- rdrobust(Y, X, c=0, h=20, b=20)
# 임계값 ±2 제외

📚 실제 연구 사례

1. Lee et al. (2008) - 현직 효과 (Incumbency Advantage)

연구 질문: 선거에서 이기는 것 자체가 다음 선거 승리 확률을 높이는가?

Running variable: 득표율 차이 (민주당 - 공화당)

Cutoff: 0% (간신히 이김 vs 간신히 짐)

처치: 현직 의원이 되는 것

결과: 다음 선거 승률

핵심 발견:

  • 간신히 이긴 후보는 다음 선거에서 약 40-50%p 더 높은 승률
  • 현직 효과는 강력하며, 인지도/자금/경험 등에서 이점
  • Sharp RDD의 교과서적 사례

2. Angrist & Lavy (1999) - 학급 규모와 학업 성취도

연구 질문: 학급 규모가 작아지면 학생 성적이 향상되는가?

Running variable: 학년당 학생 수

Cutoff: 40명 (Maimonides' Rule)

처치: 학급 분반 (소규모 학급)

결과: 표준 시험 점수

핵심 발견:

  • 41명 학년은 2개 학급으로 나뉘어 평균 20.5명
  • 40명 학년은 1개 학급으로 40명
  • 소규모 학급이 특히 읽기와 수학 점수 향상

3. Carpenter & Dobkin (2009) - 음주 연령과 사망률

연구 질문: 합법적 음주 가능 연령이 되면 사망률이 증가하는가?

Running variable: 나이 (일 단위)

Cutoff: 만 21세 (미국)

처치: 합법적 음주 가능

결과: 사망률 (특히 교통사고)

핵심 발견:

  • 21세 생일을 넘기면 사망률이 약 9% 증가
  • 주로 교통사고, 음주 관련 사고 증가
  • 정책적 시사점: 음주 연령 제한의 효과 입증

4. Card et al. (2008) - 신용카드 한도와 파산

Running variable: 신용 점수

Cutoff: 카드사의 내부 기준점

처치: 높은 신용 한도

결과: 파산 확률

핵심 발견:

  • 신용 한도 증가가 파산 확률에 미치는 영향 추정
  • Fuzzy RDD 사례 (기준 충족해도 한도가 다름)

⚠️ RDD 사용 시 주의사항

1. 외부 타당성 (External Validity) 제한

RDD는 임계값 근처에서만 인과 효과를 추정합니다.

예: 시험 70점 학생의 장학금 효과를 추정할 수 있지만, 50점 또는 90점 학생에게는 효과가 다를 수 있습니다.

2. Running Variable 조작

  • 학생이 점수를 조작할 수 있다면 RDD 무효
  • 기업이 매출을 조정할 수 있다면 문제
  • 해결책: McCrary 밀도 테스트로 검증

3. 다른 정책의 동시 변화

임계값에서 여러 정책이 동시에 바뀌면 어떤 효과인지 알 수 없습니다.

예: 소득 100만원 이하면 동시에 식비 지원 + 교통비 지원 + 의료비 지원 → 어떤 지원의 효과인지 분리 불가

4. 대역폭 선택의 자의성

  • 대역폭에 따라 결과가 달라질 수 있음
  • 해결책:
    • 최적 대역폭 알고리즘 사용 (IK, CCT)
    • 여러 대역폭으로 강건성 검증
    • 결과를 그래프로 시각화

5. 샘플 크기

RDD는 임계값 근처 데이터만 사용하므로 유효 샘플 크기가 작습니다.

전체 1000명 데이터가 있어도, 대역폭 내에는 100명만 있을 수 있습니다. → 검정력(power) 낮을 수 있음

📝 퀴즈: 학습 내용 확인

Q1. RDD의 핵심 가정은 무엇인가요?

A. 처치와 결과가 독립적이다
B. 임계값 근처에서 처치 배정이 사실상 무작위다
C. 모든 개체가 동일한 처치 효과를 받는다
D. Running variable이 정규분포를 따른다
정답: B
RDD의 핵심은 임계값 바로 위와 아래의 개체들이 매우 유사하여 처치 배정이 사실상 무작위라는 "국소 무작위화" 가정입니다.

Q2. Sharp RDD와 Fuzzy RDD의 차이는?

A. Sharp는 선형, Fuzzy는 비선형 회귀를 사용한다
B. Sharp는 처치 확률이 0→1로 완전히 점프하지만, Fuzzy는 불완전하게 점프한다
C. Sharp는 편향이 크고, Fuzzy는 분산이 크다
D. Sharp는 대역폭이 필요하지 않다
정답: B
Sharp RDD는 임계값에서 처치 확률이 0에서 1로 완벽하게 점프하지만, Fuzzy RDD는 불완전한 컴플라이언스로 인해 불완전하게 점프합니다. Fuzzy RDD는 도구변수(IV) 방법으로 추정합니다.

Q3. McCrary 밀도 테스트의 목적은?

A. Running variable의 조작 여부를 검증한다
B. 최적 대역폭을 선택한다
C. 처치 효과의 이질성을 테스트한다
D. 공변량의 균형을 검정한다
정답: A
McCrary 밀도 테스트는 Running variable의 밀도가 임계값에서 연속적인지 확인합니다. 만약 불연속이 있다면 개체들이 임계값을 넘기 위해 조작했을 가능성이 있습니다.

Q4. 대역폭(bandwidth)이 좁을 때의 장단점은?

A. 편향과 분산 모두 감소한다
B. 편향은 감소하지만 분산은 증가한다
C. 편향은 증가하지만 분산은 감소한다
D. 편향과 분산 모두 증가한다
정답: B
좁은 대역폭은 임계값에 가까운 데이터만 사용하므로 국소 무작위화 가정이 더 타당해져 편향(bias)이 감소합니다. 하지만 샘플 크기가 줄어 분산(variance)이 증가합니다. 최적 대역폭은 MSE(평균 제곱 오차)를 최소화하는 균형점입니다.

Q5. 다음 중 RDD를 적용하기 적절한 상황은?

A. 온라인 쇼핑몰에서 무작위로 할인 쿠폰을 제공
B. GPA 3.5 이상 학생에게만 장학금 지급
C. 자발적으로 신청한 사람에게만 직업훈련 제공
D. 성별에 따라 다른 프로그램 배정
정답: B
RDD는 연속 변수의 임계값에 의해 처치가 결정되는 상황에 적합합니다. GPA 3.5는 명확한 임계값이고, 3.49와 3.51 학생은 거의 동일하므로 RDD의 국소 무작위화 가정이 타당합니다.

Q6. RDD의 주요 한계는?

A. 계산이 복잡하고 시간이 오래 걸린다
B. 임계값 근처에서만 효과를 추정하여 외부 타당성이 제한적이다
C. 관찰 데이터로는 사용할 수 없다
D. 연속형 결과 변수에만 적용 가능하다
정답: B
RDD의 주요 한계는 외부 타당성(external validity)입니다. 임계값 근처의 국소적(local) 효과만 추정하므로, 임계값에서 멀리 떨어진 개체들에게는 효과가 다를 수 있습니다.

Q7. Gelman & Imbens (2019)가 고차 다항식 사용을 권장하지 않는 이유는?

A. 계산이 너무 복잡하다
B. 해석이 어렵다
C. 임계값에서 먼 데이터에 과도하게 영향받아 추정량이 불안정하다
D. 분산이 너무 커진다
정답: C
3차 이상의 고차 다항식은 임계값에서 멀리 떨어진 데이터 포인트에 과도하게 민감하게 반응하여 추정량이 불안정해집니다. 대부분의 경우 1차(선형) 또는 2차 다항식이면 충분합니다.
