🏆 왜 RCT가 골드 스탠다드인가?

무작위 대조 실험(RCT)은 인과 효과를 추정하는 가장 신뢰할 수 있는 방법입니다. 무작위 배정을 통해 모든 교란 변수(관찰되거나 관찰되지 않은)를 처치군과 대조군에 균형있게 분포시킵니다.

💡 무작위 배정의 마법

핵심 아이디어: 처치 배정을 동전 던지기처럼 무작위로 하면...

  • ✅ 처치 여부가 다른 모든 변수와 독립적
  • ✅ 관찰된 교란 변수뿐 아니라 관찰되지 않은 교란 변수도 균형
  • ✅ 선택 편향(Selection Bias) 제거
  • ✅ 단순 평균 비교로 인과 효과 추정 가능

무작위 배정 하에서:

E[Y | T=1] - E[Y | T=0] = E[Y(1)] - E[Y(0)] = ATE

처치군과 대조군의 평균 차이 = 평균 처치 효과

🔬 Interactive 데모: 무작위 배정의 힘

무작위 배정이 있을 때와 없을 때 어떤 차이가 있는지 시뮬레이션해봅시다.

🎯 RCT 설계의 핵심 요소

1. 무작위 배정 (Randomization)

단순 무작위 배정

각 개체를 동일한 확률로 처치군/대조군에 배정

treatment = random() < 0.5 ? 1 : 0

층화 무작위 배정

중요한 변수(연령, 성별 등)별로 층을 나눈 후 각 층 내에서 무작위 배정

장점: 더 균형있는 그룹 형성

블록 무작위 배정

일정 크기의 블록 내에서 처치군/대조군 비율 보장

장점: 시간에 따른 샘플 크기 균형

2. 통제 (Control)

  • 위약 대조군 (Placebo Control): 가짜 처치를 받는 그룹
  • 일반 치료 대조군: 표준 치료를 받는 그룹
  • 무처치 대조군: 아무 처치도 받지 않는 그룹

3. 맹검 (Blinding)

유형 설명 목적
단일 맹검 (Single-blind) 참가자가 자신의 처치 배정을 모름 위약 효과 제거
이중 맹검 (Double-blind) 참가자와 연구자 모두 모름 측정 편향 제거
삼중 맹검 (Triple-blind) 참가자, 연구자, 분석가 모두 모름 분석 편향 제거

📊 샘플 크기와 통계적 검정력

통계적 검정력(Statistical Power)은 실제로 효과가 있을 때 그것을 올바르게 탐지할 확률입니다.

검정력 = 1 - β (제2종 오류 확률)

일반적으로 80% 이상을 목표로 함

샘플 크기 결정 요인

  • 효과 크기 (Effect Size): 탐지하려는 최소 효과
  • 유의 수준 (α): 제1종 오류 확률 (보통 0.05)
  • 검정력 (1-β): 보통 0.80 또는 0.90
  • 분산 (Variance): 결과 변수의 변동성

💡 실용적 지침

간단한 샘플 크기 공식 (두 그룹 평균 비교):

n ≈ 16 × (σ² / δ²)

σ: 표준편차, δ: 탐지하려는 효과 크기
(검정력 80%, 유의수준 5% 가정)

⚠️ RCT의 한계와 도전과제

🏥 윤리적 문제

  • 모든 상황에서 무작위 배정이 윤리적이지 않음
  • 예: 흡연의 효과를 테스트하기 위해 사람들에게 담배를 강제로 피우게 할 수 없음

💰 비용과 시간

  • RCT는 매우 비싸고 시간이 오래 걸림
  • 대규모 샘플이 필요한 경우 특히 그러함

🌍 외적 타당도

  • 실험 참가자가 일반 모집단을 대표하지 않을 수 있음
  • 실험 환경과 실제 환경의 차이

📉 Attrition (이탈)

  • 참가자가 중도 탈락하면 무작위성 손상
  • 특히 처치군과 대조군의 이탈 패턴이 다르면 문제

🔄 Non-compliance

  • 배정된 처치를 받지 않는 경우
  • 처치군이 처치를 거부하거나, 대조군이 처치를 받는 경우

📊 SUTVA 위배

  • 간섭 효과 (Interference): 한 사람의 처치가 다른 사람에게 영향
  • 예: 백신, 교육 프로그램

🔬 유명한 RCT 사례

1. 페니실린 효과 (1940s)

최초의 대규모 의학 RCT 중 하나. 페니실린의 효과를 입증하여 항생제 시대를 열었습니다.

2. Perry Preschool Project (1962-1967)

조기 교육 프로그램의 장기 효과를 연구. 40년 이상 추적 조사하여 교육 투자의 ROI를 입증했습니다.

3. PROGRESA/Oportunidades (Mexico, 1990s)

조건부 현금 지원 프로그램의 효과를 대규모 RCT로 평가. 개발 경제학에 혁명을 가져왔습니다.

4. 온라인 A/B 테스트

Google, Facebook 등은 매일 수천 개의 RCT를 실행하여 제품과 서비스를 개선합니다.

📝 퀴즈: 학습 내용 확인

Q1. 무작위 배정의 가장 큰 장점은?

A. 비용이 저렴하다
B. 관찰되지 않은 교란 변수도 균형있게 분포시킨다
C. 항상 윤리적이다
D. 외적 타당도가 높다
정답: B
무작위 배정의 가장 큰 장점은 우리가 측정하지 못한 교란 변수까지도 처치군과 대조군에 균형있게 분포시킨다는 것입니다.

Q2. 이중 맹검(Double-blind)의 목적은?

A. 샘플 크기를 줄이기 위해
B. 비용을 절감하기 위해
C. 위약 효과와 측정 편향을 모두 제거하기 위해
D. 윤리적 문제를 해결하기 위해
정답: C
이중 맹검은 참가자와 연구자 모두 처치 배정을 모르게 하여 위약 효과(참가자의 기대)와 측정 편향(연구자의 편견)을 모두 제거합니다.

Q3. RCT를 실행할 수 없는 상황은?

A. 약물의 효과를 테스트할 때
B. 흡연이 폐암에 미치는 영향을 테스트할 때
C. 웹사이트 디자인을 테스트할 때
D. 교육 프로그램을 테스트할 때
정답: B
사람들에게 무작위로 흡연을 시키는 것은 윤리적으로 불가능합니다. 이런 경우 관찰 연구 방법론을 사용해야 합니다.

Q4. 통계적 검정력을 높이는 방법은?

A. 유의 수준을 낮춘다 (α 감소)
B. 샘플 크기를 늘린다
C. 효과 크기를 줄인다
D. 대조군을 제거한다
정답: B
샘플 크기를 늘리면 추정의 정밀도가 높아져 통계적 검정력이 증가합니다. 다른 방법으로는 측정의 정밀도를 높이거나 공변량을 통제하는 것이 있습니다.
