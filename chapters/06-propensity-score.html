성향 점수 방법 (Propensity Score Methods)

관찰 데이터에서 인과 효과를 추정하는 강력한 도구인 성향 점수의 개념과 활용법을 학습합니다.

📖 학습 목표

  • 성향 점수(Propensity Score)의 정의와 이론적 근거 이해
  • 성향 점수 매칭(Matching) 방법 학습
  • 역확률 가중치(IPW) 방법 학습
  • 이중 강건 추정(Doubly Robust Estimation) 이해

🎯 성향 점수란?

성향 점수(Propensity Score)는 주어진 공변량(covariates)을 가진 개체가 처치를 받을 확률입니다.

e(X) = P(T = 1 | X)

X: 공변량(관찰된 교란 변수들)
T: 처치 배정
e(X): 성향 점수

💡 핵심 아이디어

고차원의 공변량 X를 1차원의 성향 점수 e(X)로 요약할 수 있습니다. 성향 점수가 같은 개체들은 관찰된 공변량 측면에서 "유사"하므로, 이들을 비교하면 유사-무작위 실험을 만들 수 있습니다!

Rosenbaum-Rubin 정리 (1983)

✅ 성향 점수의 이론적 근거

정리: 주어진 공변량 X에 대해 (Y(0), Y(1)) ⊥ T | X 이면,

(Y(0), Y(1)) ⊥ T | e(X)

즉, X로 조건화하는 것과 e(X)로 조건화하는 것이 동일한 효과! 복잡한 다차원 문제를 1차원으로 축약할 수 있습니다.

📊 성향 점수 추정

실제로는 성향 점수를 알 수 없으므로 데이터로부터 추정해야 합니다.

로지스틱 회귀 (가장 일반적)

Python 
from sklearn.linear_model import LogisticRegression

# 성향 점수 모델 추정
ps_model = LogisticRegression()
ps_model.fit(X, treatment)

# 성향 점수 예측
propensity_scores = ps_model.predict_proba(X)[:, 1]

머신러닝 방법

  • Random Forest: 비선형 관계 포착
  • Gradient Boosting: 높은 예측 성능
  • Neural Networks: 복잡한 패턴 학습

⚠️ 주의사항

성향 점수 모델의 목표는 예측이 아니라 균형(balance)입니다. 모델 선택 시 예측 정확도보다는 공변량 균형을 우선시해야 합니다.

🔬 Interactive 데모: 성향 점수 매칭

성향 점수 매칭이 어떻게 처치군과 대조군을 균형있게 만드는지 시뮬레이션해봅시다.

🔧 성향 점수 활용 방법

1. 매칭 (Matching)

성향 점수가 유사한 처치군과 대조군 개체를 짝지어 비교합니다.

1:1 최근접 매칭

각 처치 개체에 가장 가까운 대조 개체 하나를 매칭

for each treated unit:
    find nearest control
    create matched pair

캘리퍼 매칭

일정 거리(캘리퍼) 내의 개체만 매칭

장점: 나쁜 매칭 방지

K:1 매칭

각 처치 개체에 K개의 대조 개체를 매칭

장점: 분산 감소

2. 역확률 가중치 (Inverse Probability Weighting, IPW)

성향 점수의 역수로 가중치를 부여하여 유사-모집단(pseudo-population)을 만듭니다.

가중치:

wi = Ti / e(Xi) + (1 - Ti) / (1 - e(Xi))

ATE 추정:

τ̂IPW = (1/n) Σ[wi × Ti × Yi] - (1/n) Σ[wi × (1-Ti) × Yi]

Python 
# IPW 추정
weights = treatment / ps + (1 - treatment) / (1 - ps)

weighted_treated = np.sum(weights * treatment * outcome)
weighted_control = np.sum(weights * (1 - treatment) * outcome)

ATE_IPW = weighted_treated / np.sum(treatment) - \
          weighted_control / np.sum(1 - treatment)

3. 층화 (Stratification)

성향 점수를 기준으로 개체들을 여러 층으로 나눈 후, 각 층 내에서 처치 효과를 추정합니다.

💡 Rosenbaum & Rubin의 발견

성향 점수를 기준으로 5개 층으로 나누면 공변량 편향의 90% 이상을 제거할 수 있습니다.

4. 공변량 조정 (Covariate Adjustment)

회귀 모델에 성향 점수를 포함시킵니다.

Python 
# 성향 점수로 조정된 회귀
model = sm.OLS(outcome, sm.add_constant(
    pd.DataFrame({
        'treatment': treatment,
        'ps': propensity_scores
    })
))
results = model.fit()

🛡️ 이중 강건 추정 (Doubly Robust Estimation)

성향 점수 모델과 결과 모델을 모두 사용하는 방법입니다. 둘 중 하나만 올바르게 명시되어도 일치 추정량을 얻을 수 있습니다!

DR 추정량:

τ̂DR = (1/n) Σ[
  (Ti/e(Xi)) × (Yi - μ̂1(Xi)) + μ̂1(Xi)
  - ((1-Ti)/(1-e(Xi))) × (Yi - μ̂0(Xi)) - μ̂0(Xi)
]

💡 이중 보호 (Double Protection)

  • 성향 점수 모델이 맞고 결과 모델이 틀려도 OK
  • 결과 모델이 맞고 성향 점수 모델이 틀려도 OK
  • 둘 다 틀리면... 문제 발생

✅ 균형 진단 (Balance Diagnostics)

성향 점수 방법의 성공 여부는 공변량 균형으로 평가합니다.

표준화 평균 차이 (Standardized Mean Difference, SMD)

SMD = (X̄treated - X̄control) / √((s²treated + s²control)/2)

일반적으로 |SMD| < 0.1이면 좋은 균형으로 간주

Love Plot

매칭 전후의 SMD를 시각화하여 균형 개선을 확인합니다.

✅ 균형 검사 체크리스트

  • 모든 공변량의 SMD < 0.1
  • 처치군과 대조군의 성향 점수 분포 겹침 확인
  • 극단적 가중치(extreme weights) 확인
  • 샘플 크기 충분성 확인

📝 퀴즈: 학습 내용 확인

Q1. 성향 점수의 정의는?

A. 처치의 효과를 받을 확률
B. 주어진 공변량을 가진 개체가 처치를 받을 확률
C. 결과 변수의 기댓값
D. 교란 변수의 영향력
정답: B
성향 점수 e(X) = P(T=1|X)는 관찰된 공변량 X를 가진 개체가 처치를 받을 조건부 확률입니다.

Q2. 이중 강건 추정의 장점은?

A. 항상 정확한 추정값을 제공한다
B. 성향 점수 모델과 결과 모델 중 하나만 맞아도 일치 추정량을 제공한다
C. 계산이 가장 간단하다
D. 모든 가정이 필요 없다
정답: B
이중 강건 추정은 두 모델 중 하나만 올바르게 명시되어도 일치 추정량(consistent estimator)을 제공하는 "이중 보호" 특성이 있습니다.

Q3. 성향 점수 매칭 후 가장 중요한 검사는?

A. R-squared 검사
B. 공변량 균형 검사
C. 정규성 검사
D. 다중공선성 검사
정답: B
성향 점수 방법의 핵심은 처치군과 대조군 사이의 공변량 균형을 달성하는 것입니다. 표준화 평균 차이(SMD) 등으로 균형을 반드시 확인해야 합니다.

Q4. IPW에서 극단적 가중치가 발생하는 경우는?

A. 샘플 크기가 클 때
B. 성향 점수가 0이나 1에 가까울 때
C. 처치 효과가 클 때
D. 공변량이 많을 때
정답: B
성향 점수가 0이나 1에 가까우면 가중치 1/e(X) 또는 1/(1-e(X))가 매우 커져 극단적 가중치가 발생합니다. 이는 추정의 불안정성을 야기할 수 있습니다.
