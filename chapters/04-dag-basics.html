🌳 DAG란 무엇인가?

DAG (Directed Acyclic Graph)는 인과관계를 시각적으로 표현하는 도구입니다. 변수들을 노드(nodes)로, 인과관계를 화살표(directed edges)로 나타냅니다.

💡 DAG의 구성 요소

  • 노드 (Nodes): 변수들 (예: X, Y, Z)
  • 방향 엣지 (Directed Edges): 인과관계 화살표 (X → Y: "X가 Y를 유발")
  • 비순환 (Acyclic): 순환 고리가 없음 (X → Y → Z → X 같은 것 불가)

간단한 DAG 예시

직접 인과관계

X → Y
"X가 Y에 직접적인 인과 효과를 가짐"

매개 (Mediation)

X → M → Y
"X의 효과가 M을 통해 Y에 전달됨"

교란 (Confounding)

C → X, C → Y
"C가 X와 Y 모두에 영향"

🎯 DAG의 세 가지 기본 구조

1. Chain (연쇄): X → M → Y

특징

  • X가 M을 통해 Y에 영향을 미침
  • M을 통제하면 X와 Y의 연관성이 사라짐
  • 예: 교육(X) → 기술(M) → 소득(Y)

2. Fork (분기): X ← C → Y

특징

  • C가 X와 Y의 공통 원인 (교란 변수)
  • C를 통제하면 X와 Y가 독립적
  • 예: 나이(C) → 운동량(X), 나이(C) → 건강(Y)

3. Collider (충돌): X → C ← Y

⚠️ 중요한 특징

  • C는 X와 Y의 공통 결과
  • C를 통제하면 X와 Y 사이에 인위적 연관성 생성!
  • 예: 재능(X) → 성공(C) ← 노력(Y)
  • Collider는 통제하면 안 됨!

🔬 Interactive 데모: Collider Bias 체험

Collider를 통제했을 때 어떤 일이 발생하는지 시뮬레이션해봅시다.

해석:

🔗 경로 (Paths)와 d-separation

경로의 종류

인과 경로 (Causal Path)

처치에서 결과로 가는 방향성 경로

X → M → Y

모든 화살표가 X에서 Y 방향으로 향함

Backdoor Path

처치로 들어오는 화살표가 있는 경로

X ← C → Y

교란을 만드는 경로 (차단 필요!)

d-separation (방향적 분리)

두 변수가 d-separated되어 있다면, 주어진 조건 하에서 통계적으로 독립입니다.

💡 d-separation 규칙

경로가 차단되는 경우:

  1. Chain이나 Fork: 중간 변수를 통제하면 차단됨
  2. Collider: 중간 변수나 그 자손을 통제하지 않으면 차단됨

실제 예시: 복잡한 DAG

질문: X가 Y에 미치는 인과 효과를 추정하려면 무엇을 통제해야 할까요?

✅ 답: C를 통제

  • 인과 경로: X → Y (직접), X → M → Y (간접)
  • Backdoor path: X ← C → Y (차단 필요)
  • M은 매개변수이므로 통제하면 안 됨 (간접 효과 측정 불가)
  • D는 collider이므로 통제하면 안 됨

🎓 Backdoor Criterion

X가 Y에 미치는 인과 효과를 식별하기 위해 어떤 변수들을 통제해야 하는지 결정하는 규칙입니다.

Backdoor Criterion이 만족되려면:

  1. 통제 변수 집합 Z가 X의 자손을 포함하지 않음
  2. Z가 X에서 Y로 가는 모든 backdoor path를 차단함

💡 실용적 지침

  • ✅ 교란 변수는 통제하기
  • ✅ Backdoor path를 차단하는 변수 통제
  • ❌ Collider는 통제하지 않기
  • ❌ 매개변수는 (보통) 통제하지 않기
  • ❌ 처치의 자손은 통제하지 않기

📝 퀴즈: 학습 내용 확인

Q1. DAG에서 "Acyclic"이 의미하는 것은?

A. 변수가 하나뿐이다
B. 순환 고리가 없다
C. 화살표가 없다
D. 모든 변수가 독립적이다
정답: B
Acyclic은 "순환이 없다"는 의미로, X → Y → Z → X 같은 순환 구조가 없어야 합니다. 인과관계는 시간의 방향을 따르므로 순환할 수 없습니다.

Q2. Collider 구조 X → C ← Y에서 C를 통제하면?

A. X와 Y가 독립적이 된다
B. X와 Y 사이에 인위적 연관성이 생긴다
C. 인과 효과를 정확히 추정할 수 있다
D. 아무 변화가 없다
정답: B
Collider를 통제하면 "collider bias"가 발생하여 원래 독립적이던 X와 Y 사이에 인위적인 연관성이 만들어집니다. 이를 "Berkson's paradox"라고도 합니다.

Q3. Fork 구조 X ← C → Y에서 backdoor path를 차단하려면?

A. C를 통제한다
B. X를 통제한다
C. Y를 통제한다
D. 아무것도 통제하지 않는다
정답: A
Fork 구조에서 공통 원인 C를 통제하면 X와 Y 사이의 backdoor path가 차단되어 인과 효과를 올바르게 추정할 수 있습니다.

Q4. 다음 중 Backdoor Criterion을 위배하는 것은?

A. 교란 변수를 통제 집합에 포함
B. 처치의 자손을 통제 집합에 포함
C. 처치와 결과의 공통 원인을 통제
D. Backdoor path를 차단하는 변수 통제
정답: B
Backdoor Criterion의 첫 번째 조건은 통제 변수 집합이 처치의 자손을 포함하지 않아야 한다는 것입니다. 처치의 자손을 통제하면 "post-treatment bias"가 발생할 수 있습니다.
