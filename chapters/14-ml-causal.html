🤖 왜 머신러닝이 필요한가?

전통적 인과추론 방법은 선형 모델이나 간단한 비모수 방법에 의존했습니다. 하지만 실제 데이터는 복잡한 비선형 관계를 가지고 있으며, 고차원 공변량이 존재합니다.

🎯 ML의 장점

  • 복잡한 비선형 관계 포착
  • 고차원 데이터 처리
  • 자동 특징 선택
  • 이질적 효과 발견

⚠️ ML의 도전과제

  • 정규화 편향 (Regularization Bias)
  • 과적합 위험
  • 불확실성 정량화 어려움
  • 해석 가능성 부족

🎓 Double/Debiased Machine Learning (DML)

Victor Chernozhukov 등이 제안한 DML은 머신러닝의 정규화 편향을 제거하면서 고차원 데이터에서 인과 효과를 추정하는 방법입니다.

핵심 아이디어: Orthogonalization

💡 직교화 (Orthogonalization)

방해 매개변수(nuisance parameters)를 교차 적합(cross-fitting)으로 추정하여 관심 매개변수에 대한 추정의 편향을 제거합니다.

DML 알고리즘

  1. 데이터 분할: 데이터를 K개의 폴드로 나눔
  2. 교차 적합: 각 폴드에 대해
    • 나머지 데이터로 방해 함수 추정 (E[Y|X], E[T|X])
    • 해당 폴드에서 잔차 계산
  3. 최종 추정: 모든 잔차를 사용하여 처치 효과 추정
Python 
from econml.dml import DML
from sklearn.ensemble import RandomForestRegressor

# DML 모델 초기화
dml = DML(
    model_y=RandomForestRegressor(),
    model_t=RandomForestRegressor(),
    discrete_treatment=True
)

# 적합
dml.fit(Y, T, X=X, W=W)

# CATE 추정
treatment_effects = dml.effect(X)

✅ DML의 장점

  • 정규화 편향 제거
  • 임의의 ML 알고리즘 사용 가능
  • √n-일치성과 점근적 정규성
  • 타당한 신뢰구간 제공

🌲 Causal Forests

Susan Athey와 Guido Imbens가 개발한 Causal Forest는 랜덤 포레스트를 인과추론에 맞게 수정한 방법입니다. 이질적 처치 효과(CATE)를 추정하는 데 강력합니다.

핵심 원리

1. Honest Trees

데이터를 분할과 추정에 각각 다르게 사용하여 과적합을 방지합니다.

2. Adaptive Splits

처치 효과의 이질성을 최대화하는 방향으로 분할합니다.

3. Subsampling

각 트리는 데이터의 일부만 사용하여 다양성을 확보합니다.

Python 
from econml.grf import CausalForest

# Causal Forest 초기화
cf = CausalForest(
    n_estimators=1000,
    min_samples_leaf=5,
    honest=True
)

# 적합
cf.fit(X, T, Y)

# CATE 추정
cate = cf.predict(X)

# 특징 중요도
importances = cf.feature_importances_

CATE: 조건부 평균 처치 효과

τ(x) = E[Y(1) - Y(0) | X = x]

특정 특징 X=x를 가진 개체들의 평균 처치 효과

💡 CATE의 활용

  • 개인화된 치료: 누구에게 처치가 가장 효과적인가?
  • 타겟팅: 어떤 고객에게 프로모션을 제공할 것인가?
  • 정책 설계: 정책의 수혜 대상 식별
  • 이질성 발견: 효과가 다른 하위 그룹 찾기

📊 Meta-Learners

Meta-learner는 기존 ML 알고리즘을 조합하여 CATE를 추정하는 프레임워크입니다.

1. S-Learner (Single Model)

# 처치를 특징으로 포함
X_with_T = np.column_stack([X, T])
model = RandomForestRegressor()
model.fit(X_with_T, Y)

# CATE 추정
tau = model.predict(np.column_stack([X, 1])) - \
      model.predict(np.column_stack([X, 0]))

장점: 간단
단점: 처치 효과가 작을 때 부정확

2. T-Learner (Two Model)

# 처치군과 대조군 별도 모델
model_0 = RandomForestRegressor()
model_1 = RandomForestRegressor()

model_0.fit(X[T==0], Y[T==0])
model_1.fit(X[T==1], Y[T==1])

# CATE 추정
tau = model_1.predict(X) - model_0.predict(X)

장점: 유연성
단점: 샘플 크기가 작으면 불안정

3. X-Learner

T-learner의 개선 버전으로, 잔차 모델링을 통해 더 나은 추정을 제공합니다.

✅ Meta-learner 선택 가이드

  • S-learner: 처치 효과가 크고 단순할 때
  • T-learner: 샘플이 충분하고 높은 유연성 필요
  • X-learner: 불균형 데이터 또는 작은 처치 효과

📚 실제 응용 사례

1. 개인화된 의료 (Precision Medicine)

환자의 특성에 따라 어떤 치료가 가장 효과적인지 예측하여 개인화된 치료 계획을 수립합니다.

2. 타겟 마케팅 (Uplift Modeling)

프로모션에 반응할 가능성이 높은 고객을 식별하여 마케팅 ROI를 최대화합니다.

3. 정책 최적화

교육, 복지 프로그램 등에서 수혜 대상을 효과적으로 선정하여 제한된 자원을 최적 배분합니다.

4. A/B 테스트 분석

단순 평균 효과를 넘어 어떤 사용자 세그먼트에서 새로운 기능이 효과적인지 파악합니다.
