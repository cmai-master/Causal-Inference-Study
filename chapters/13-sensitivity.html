민감도 분석 (Sensitivity Analysis)

관찰되지 않은 교란에 대한 인과 추론의 강건성 평가

🎯 왜 민감도 분석인가?

관찰 연구의 근본적 문제: unconfoundedness 가정은 검증 불가능
관찰되지 않은 교란이 얼마나 강해야 결론이 바뀌는지 평가합니다.

1. Rosenbaum Bounds

매칭 연구에서 관찰되지 않은 교란의 영향 평가

민감도 파라미터 Γ:

1/Γ ≤ oddsi/oddsj ≤ Γ

Γ = 1: 무교란 (이상적)
Γ = 2: 한 개체가 다른 개체보다 처치받을 확률이 2배까지 차이
Γ가 클수록 결론이 강건함

R 
library(rbounds)

# Rosenbaum bounds
psens(
    x = treated_outcomes,
    y = control_outcomes,
    Gamma = seq(1, 5, 0.1)
)

2. E-values (VanderWeele & Ding, 2017)

관찰되지 않은 교란 변수가 얼마나 강해야 추정된 효과가 사라지는지

E-value:

E-value = RR + √(RR × (RR - 1))

RR: 위험비 또는 효과 추정값

✅ E-value 해석

E-value = 3.0이면:
관찰되지 않은 교란이 처치와 결과 모두에 3배의 연관성을 가져야 관찰된 효과가 완전히 설명됨

R 
library(EValue)

# E-value 계산
evalues.RR(
    est = 2.5,  # 추정된 위험비
    lo = 1.8,   # 95% CI 하한
    hi = 3.5,   # 95% CI 상한
    true = 1    # 귀무가설
)

3. 부분 식별 (Partial Identification)

Manski Bounds: 최악의 경우 시나리오 하에서도 효과의 범위 제공

4. 벤치마킹

관찰된 교란과 비교하여 관찰되지 않은 교란의 강도 평가

R 
library(sensemakr)

# 민감도 분석
sense <- sensemakr(
    model = lm_model,
    treatment = "treatment",
    benchmark_covariates = "observed_confounder",
    kd = 1  # 관찰된 교란만큼 강한 미관찰 교란
)

plot(sense)

💡 민감도 분석 체크리스트

  1. □ 주 분석 후 항상 민감도 분석 수행
  2. □ 다양한 방법 적용 (Rosenbaum, E-values, 벤치마킹)
  3. □ 결과를 논문에 보고
  4. □ 합리적인 교란 시나리오 고려
  5. □ 결론의 강건성 평가
