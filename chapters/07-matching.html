🎓 이론적 기초

1. 매칭의 핵심 아이디어

매칭(Matching)은 관찰 연구를 준실험(quasi-experiment)으로 변환하는 전처리 방법입니다. 공변량이 유사한 처치군과 대조군 개체를 짝지어 counterfactual comparison을 근사합니다.

💡 근본 원리

Matching Principle (Rubin, 1973):

공변량 X가 동일한 개체들 사이에서는 처치 배정이 무작위적인 것처럼 작동합니다. 따라서 X를 매칭하면 X로 인한 교란을 제거할 수 있습니다.

조건부 독립 가정 (CIA):

(Y(0), Y(1)) ⊥ T | X

주어진 X에 대해, 잠재적 결과가 처치 배정과 독립
= Unconfoundedness (Rosenbaum & Rubin, 1983)
= Selection on Observables
= Ignorability (Rubin, 1978)

2. 식별 가정 (Identification Assumptions)

Assumption 1: Unconfoundedness

(Y(0), Y(1)) ⊥ T | X

관찰된 공변량으로 조건화하면 처치 배정이 외생적

Assumption 2: Common Support

0 < P(T=1|X) < 1

모든 공변량 값에 대해 처치/대조군 모두 존재

Assumption 3: SUTVA

Yi = TiYi(1) + (1-Ti)Yi(0)

간섭 없음, 처치 버전의 일관성

⚠️ Unconfoundedness의 강한 가정

이 가정은 검증 불가능(untestable)합니다. 관찰되지 않은 교란이 없다는 것을 데이터만으로는 확인할 수 없기 때문입니다. 따라서:

  • 가능한 모든 관련 공변량 포함
  • 도메인 지식 활용
  • 민감도 분석 수행
  • 실험 결과와 비교 (가능한 경우)

3. 매칭 추정량의 형식화

ATT 추정량 (일반형):

τ̂ATT = (1/n1) Σi:Ti=1 [Yi - Σj∈M(i) wij Yj]

M(i): 개체 i와 매칭된 대조군 집합
wij: 매칭 가중치 (Σwij = 1)

4. 매칭 vs 회귀 조정

특성 매칭 회귀 조정
접근 방식 비모수적 (nonparametric) 모수적 (parametric)
함수형 가정 불필요 필요 (선형성 등)
Common support 명시적으로 강제 외삽(extrapolation) 위험
균형 진단 직접적 간접적
효율성 낮을 수 있음 높음 (올바른 명시 시)
강건성 높음 모델 오명시에 취약

🔧 매칭 알고리즘

1. Exact Matching (정확 매칭)

공변량이 완전히 동일한 개체들만 매칭합니다.

Python 
from causalinference import CausalModel

# Exact matching
cm = CausalModel(Y, T, X)
cm.est_via_matching(matches=1, bias_adj=False)

# 결과 확인
print(cm.estimates)

✅ 장점

  • 완벽한 균형 달성
  • 구현이 간단
  • 해석이 명확

❌ 단점

  • 고차원에서 매칭 불가 (차원의 저주)
  • 연속형 변수에 부적합
  • 많은 개체가 매칭되지 않음

2. Nearest Neighbor Matching (최근접 이웃 매칭)

거리 측도 d(Xi, Xj)를 정의하고, 가장 가까운 개체를 매칭합니다.

매칭 함수:

M(i) = argminj:Tj≠Ti d(Xi, Xj)

거리 측도 선택

Euclidean Distance

d(Xi, Xj) = √(Σ(Xik - Xjk)²)

스케일에 민감 → 표준화 필요

Mahalanobis Distance

d(Xi, Xj) = √((Xi-Xj)'Σ-1(Xi-Xj))

공변량 간 상관관계 고려

Propensity Score Distance

d(Xi, Xj) = |e(Xi) - e(Xj)|

차원 축소 + 균형화

Python 
from sklearn.neighbors import NearestNeighbors

# 1:1 Nearest Neighbor Matching
def nn_matching(X_treated, X_control, Y_treated, Y_control, k=1):
    # NearestNeighbors 모델
    nbrs = NearestNeighbors(n_neighbors=k, metric='mahalanobis',
                           metric_params={'V': np.cov(X_control.T)})
    nbrs.fit(X_control)

    # 각 처치 개체에 대한 최근접 이웃 찾기
    distances, indices = nbrs.kneighbors(X_treated)

    # ATT 추정
    matched_control = Y_control[indices].mean(axis=1)
    att = (Y_treated - matched_control).mean()

    return att, indices

변형: K:1 Matching with Replacement

  • K:1 Matching: 각 처치 개체에 K개의 대조군 매칭
    • 장점: 분산 감소
    • 단점: 편향 증가 (더 먼 개체 포함)
  • With Replacement: 같은 대조군을 여러 번 사용 가능
    • 장점: 매칭 품질 향상
    • 단점: 분산 추정 복잡

3. Caliper Matching (캘리퍼 매칭)

최대 허용 거리(caliper) ε 내의 개체만 매칭합니다.

M(i) = {j : Tj≠Ti and d(Xi, Xj) < ε}

💡 Caliper 선택 규칙 (Rosenbaum & Rubin, 1985)

성향 점수 매칭의 경우: ε = 0.25 × SD(logit(e(X)))
이는 약 0.2 × SD(e(X))와 동일

R 
library(MatchIt)

# Caliper matching
m.out <- matchit(treatment ~ age + education + income,
                 data = mydata,
                 method = "nearest",
                 distance = "logit",
                 caliper = 0.25)

4. Coarsened Exact Matching (CEM)

Iacus, King & Porro (2012)가 제안한 방법으로, 연속형 변수를 구간으로 나눈 후 exact matching을 수행합니다.

✅ CEM의 장점

  • Monotonic Imbalance Bounding (MIB): 거친 분할(coarsening)이 증가하면 불균형이 단조 감소
  • 사전 분석 없이 균형 달성
  • 모델 의존성 감소
  • Common support 자동 제한
R 
library(cem)

# Coarsened Exact Matching
mat <- cem(treatment = "treat",
           data = mydata,
           drop = "outcome",
           cutpoints = list(age = c(25, 40, 60),
                           income = "sturges"))

# ATT 추정
att(mat, outcome ~ treat, data = mydata)

5. Genetic Matching

Diamond & Sekhon (2013)의 방법으로, 유전 알고리즘을 사용하여 최적의 가중치 행렬을 자동으로 찾아 균형을 극대화합니다.

일반화된 Mahalanobis 거리:

d(Xi, Xj) = √((Xi-Xj)'W(Xi-Xj))

W는 유전 알고리즘으로 최적화

R 
library(Matching)

# Genetic Matching
genout <- GenMatch(Tr = treatment, X = X,
                   pop.size = 1000,
                   max.generations = 100,
                   print.level = 0)

mout <- Match(Y = outcome, Tr = treatment, X = X,
              Weight.matrix = genout)

6. Optimal Matching

전역 최소 거리(global minimum distance)를 달성하는 매칭을 찾습니다. Network flow 알고리즘 사용.

💡 Greedy vs Optimal

  • Greedy (NN): 각 단계에서 최선 선택 → 빠름, 지역 최적
  • Optimal: 전역 최소화 → 느림, 전역 최적

📊 균형 진단 (Balance Diagnostics)

매칭의 성공은 처치 효과 추정이 아닌 공변량 균형으로 평가합니다.

1. Standardized Mean Difference (SMD)

SMD = (X̄treated - X̄control) / √((s²treated + s²control)/2)

기준: |SMD| < 0.1 (엄격), < 0.25 (일반적)

2. Variance Ratio

VR = s²treated / s²control

기준: 0.5 < VR < 2.0

3. Love Plot

매칭 전후의 모든 공변량 SMD를 시각화

Python 
import matplotlib.pyplot as plt

def plot_love(covariates, treated, control,
              treated_matched, control_matched):
    # 매칭 전후 SMD 계산
    smd_before = []
    smd_after = []

    for cov in covariates:
        # Before matching
        mean_diff = treated[cov].mean() - control[cov].mean()
        pooled_sd = np.sqrt((treated[cov].var() + control[cov].var()) / 2)
        smd_before.append(mean_diff / pooled_sd)

        # After matching
        mean_diff = treated_matched[cov].mean() - control_matched[cov].mean()
        pooled_sd = np.sqrt((treated_matched[cov].var() +
                            control_matched[cov].var()) / 2)
        smd_after.append(mean_diff / pooled_sd)

    # Plot
    fig, ax = plt.subplots(figsize=(10, 6))
    y_pos = range(len(covariates))

    ax.scatter(smd_before, y_pos, label='Before', marker='o', s=100)
    ax.scatter(smd_after, y_pos, label='After', marker='x', s=100)
    ax.axvline(x=0, color='black', linestyle='-', linewidth=0.5)
    ax.axvline(x=-0.1, color='red', linestyle='--', linewidth=0.5)
    ax.axvline(x=0.1, color='red', linestyle='--', linewidth=0.5)

    ax.set_yticks(y_pos)
    ax.set_yticklabels(covariates)
    ax.set_xlabel('Standardized Mean Difference')
    ax.set_title('Love Plot: Covariate Balance')
    ax.legend()

    plt.tight_layout()
    plt.show()

💻 실전 구현

완전한 매칭 파이프라인 (Python)

Python 
import pandas as pd
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors
from scipy import stats

class MatchingEstimator:
    def __init__(self, method='nearest', k=1, caliper=None,
                 replacement=False):
        self.method = method
        self.k = k
        self.caliper = caliper
        self.replacement = replacement
        self.matches = None

    def fit(self, X, treatment, outcome):
        """매칭 수행"""
        self.X = X
        self.treatment = treatment
        self.outcome = outcome

        # 성향 점수 추정
        ps_model = LogisticRegression(max_iter=1000)
        ps_model.fit(X, treatment)
        self.ps = ps_model.predict_proba(X)[:, 1]

        # 매칭
        if self.method == 'nearest':
            self._nearest_neighbor_matching()
        elif self.method == 'optimal':
            self._optimal_matching()
        elif self.method == 'genetic':
            self._genetic_matching()

        return self

    def _nearest_neighbor_matching(self):
        """최근접 이웃 매칭"""
        treated_idx = np.where(self.treatment == 1)[0]
        control_idx = np.where(self.treatment == 0)[0]

        # NearestNeighbors 모델
        if self.caliper:
            radius = self.caliper
        else:
            radius = np.inf

        nbrs = NearestNeighbors(n_neighbors=self.k,
                               metric='euclidean',
                               radius=radius)
        nbrs.fit(self.ps[control_idx].reshape(-1, 1))

        # 매칭
        distances, indices = nbrs.kneighbors(
            self.ps[treated_idx].reshape(-1, 1)
        )

        # Caliper 적용
        if self.caliper:
            valid = distances[:, 0] <= self.caliper
            treated_idx = treated_idx[valid]
            indices = indices[valid]

        self.matches = {
            'treated': treated_idx,
            'control': control_idx[indices]
        }

    def estimate_att(self):
        """ATT 추정"""
        treated_idx = self.matches['treated']
        control_idx = self.matches['control']

        Y_treated = self.outcome[treated_idx]
        Y_control = self.outcome[control_idx].mean(axis=1)

        att = (Y_treated - Y_control).mean()
        se = (Y_treated - Y_control).std() / np.sqrt(len(Y_treated))

        return {
            'ATT': att,
            'SE': se,
            'CI_lower': att - 1.96 * se,
            'CI_upper': att + 1.96 * se,
            'n_matched': len(treated_idx)
        }

    def balance_diagnostics(self):
        """균형 진단"""
        treated_idx = self.matches['treated']
        control_idx = self.matches['control'].flatten()

        balance = {}
        for i, col in enumerate(self.X.T):
            # Before matching
            smd_before = self._compute_smd(
                col[self.treatment == 1],
                col[self.treatment == 0]
            )

            # After matching
            smd_after = self._compute_smd(
                col[treated_idx],
                col[control_idx]
            )

            balance[f'X{i}'] = {
                'SMD_before': smd_before,
                'SMD_after': smd_after,
                'improvement': abs(smd_before) - abs(smd_after)
            }

        return pd.DataFrame(balance).T

    def _compute_smd(self, x1, x2):
        """표준화 평균 차이 계산"""
        mean_diff = x1.mean() - x2.mean()
        pooled_std = np.sqrt((x1.var() + x2.var()) / 2)
        return mean_diff / pooled_std if pooled_std > 0 else 0


# 사용 예시
estimator = MatchingEstimator(method='nearest', k=1,
                              caliper=0.1, replacement=False)
estimator.fit(X, treatment, outcome)

# ATT 추정
results = estimator.estimate_att()
print(f"ATT: {results['ATT']:.3f} (SE: {results['SE']:.3f})")
print(f"95% CI: [{results['CI_lower']:.3f}, {results['CI_upper']:.3f}]")

# 균형 진단
balance = estimator.balance_diagnostics()
print("\n균형 진단:")
print(balance)

📚 고급 주제

1. 분산 추정 (Variance Estimation)

⚠️ 복잡한 문제

매칭 후 단순 분산 공식은 부정확합니다. 왜냐하면:

  • 매칭이 데이터 의존적 (data-dependent)
  • With replacement 시 관측치 재사용
  • 성향 점수 추정의 불확실성

해결 방법

  • Abadie-Imbens (2006) 표준오차: 매칭 불확실성 고려
  • Bootstrap: 전체 과정(성향 점수 추정 + 매칭) 반복
  • Subclassification: 층화 후 분산 계산

2. 매칭 후 회귀 조정

잔여 불균형을 제거하고 효율성을 높이기 위해 매칭 후 회귀 조정을 수행할 수 있습니다.

Python 
from sklearn.linear_model import LinearRegression

# 매칭 후 회귀 조정
matched_data = data.iloc[matched_indices]
model = LinearRegression()
model.fit(
    matched_data[['treatment'] + covariates],
    matched_data['outcome']
)

# 조정된 ATT
att_adjusted = model.coef_[0]

3. 다중 처치 (Multiple Treatments)

처치가 2개 이상일 때:

  • Pairwise matching: 각 처치 쌍에 대해 매칭
  • Generalized propensity score: 다항 로지스틱 회귀
  • Matching on generalized PS

4. 실제 연구 사례

Dehejia & Wahba (1999): NSW Job Training

연구 질문: 직업 훈련 프로그램이 수입에 미치는 영향
방법: PS matching with CPS comparison group
결과: ATT ≈ $1,794 (실험 결과와 유사)
교훈: 신중한 매칭으로 관찰 연구가 실험 결과 재현 가능

Rosenbaum (2002): Smoking and Health

연구 질문: 흡연이 건강에 미치는 영향
방법: Optimal matching + sensitivity analysis
결과: 강한 인과 증거, 관찰되지 않은 교란에도 강건
교훈: 민감도 분석의 중요성

✅ 실전 체크리스트

매칭 분석 단계

  1. □ 모든 관련 공변량 포함 확인
  2. □ Common support 확인 (PS 분포 겹침)
  3. □ 적절한 매칭 알고리즘 선택
  4. □ 매칭 수행
  5. □ 균형 진단 (SMD, variance ratio, Love plot)
  6. □ 불균형 시 재매칭 또는 회귀 조정
  7. □ ATT/ATE 추정
  8. □ 적절한 표준오차 계산
  9. □ 민감도 분석
  10. □ 결과 해석 및 보고
