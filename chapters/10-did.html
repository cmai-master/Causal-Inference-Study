🎯 DiD란 무엇인가?

이중차분법(Difference-in-Differences, DiD)은 처치군과 대조군의 시간에 따른 변화의 차이를 비교하여 인과 효과를 추정하는 준실험 설계 방법입니다.

💡 핵심 아이디어

첫 번째 차이: 각 그룹의 처치 전후 변화
두 번째 차이: 두 그룹의 변화량 차이

처치군의 변화 - 대조군의 변화 = 처치 효과

간단한 예시: 최저임금과 고용

그룹 처치 전 (2020) 처치 후 (2021) 변화 (차이)
처치군 (최저임금 인상) 100명 105명 +5명
대조군 (인상 없음) 80명 88명 +8명
DiD 추정 효과 +5 - (+8) = -3명

해석: 최저임금 인상으로 인해 고용이 3명 감소했습니다. 단순히 처치 전후를 비교하면 +5명 증가로 보이지만, 대조군도 +8명 증가했으므로 실제 효과는 -3명입니다.

📐 DiD의 수학적 표현

2×2 DiD (기본 형태)

2개 그룹 (처치/대조), 2개 시점 (전/후)

DiD 추정량:

τDiD = (ȲTreated,Post - ȲTreated,Pre) - (ȲControl,Post - ȲControl,Pre)

= 처치군의 변화 - 대조군의 변화

또는 다시 정리하면:

τDiD = (ȲTreated,Post - ȲControl,Post) - (ȲTreated,Pre - ȲControl,Pre)

= 사후 그룹 차이 - 사전 그룹 차이

회귀분석 표현

DiD는 회귀분석으로 쉽게 구현할 수 있습니다:

Yit = α + β·Treatedi + γ·Postt + δ·(Treatedi×Postt) + εit

α: 대조군, 사전 시점 평균
β: 사전 시점에서 처치군-대조군 차이
γ: 대조군의 시간 변화
δ: DiD 추정량 (처치 효과) ⭐

💡 왜 교호작용(Interaction)인가?

Treated × Post 교호작용항이 DiD 효과를 포착합니다.
이 항은 처치군이면서 동시에 사후 기간일 때만 1이 됩니다.

🔑 평행 추세 가정 (Parallel Trends Assumption)

DiD의 가장 중요한 가정입니다. 이 가정이 만족되지 않으면 DiD 추정량이 편향됩니다.

📊 평행 추세 가정

처치가 없었다면, 처치군과 대조군의 결과 변수 추세가 평행했을 것입니다.

E[Yit(0) | Treated=1] - E[Yit(0) | Treated=0] = 상수

두 그룹의 반사실 결과 차이가 시간에 불변

평행 추세 가정이 의미하는 것

✅ 허용되는 것

  • 사전 수준이 다름 (OK)
  • 두 그룹이 모두 증가/감소 (OK)
  • 증가/감소 속도가 같으면 됨

예: 처치군이 매년 +10, 대조군도 매년 +10

❌ 위배되는 경우

  • 처치군만 가속 증가
  • 대조군만 감소
  • 추세의 기울기가 다름

예: 처치군 매년 +10, 대조군 매년 +5

⚠️ 평행 추세는 검증 불가능!

평행 추세 가정은 반사실(counterfactual)에 대한 가정이므로 직접 검증할 수 없습니다.

대신 할 수 있는 것:

  • 사전 추세 분석: 처치 전 기간에 추세가 평행했는지 확인
  • Event Study: 처치 전후 동적 효과 시각화
  • Placebo Tests: 가짜 처치 시점에서 효과가 없는지 확인

🔬 Interactive 데모: DiD 시뮬레이션

평행 추세 가정이 만족되거나 위배되는 상황을 시뮬레이션해보세요.

📊 DiD가 통제하는 것

1. 시간 불변 교란 변수 (Time-Invariant Confounders)

DiD는 그룹 간 고정된 차이를 자동으로 통제합니다.

예시:

  • 지역의 문화적 특성 (변하지 않음)
  • 기업의 규모 (단기적으로 고정)
  • 개인의 능력 (시간에 불변)

이런 변수들이 처치군과 대조군에서 다르더라도, 시간에 불변하면 DiD가 자동으로 제거합니다! (차분을 통해)

2. 공통 시간 추세 (Common Time Trends)

DiD는 모든 그룹에 동일하게 영향을 미치는 시간 효과를 통제합니다.

예시:

  • 경기 순환 (모든 지역이 동일하게 영향 받음)
  • 계절성 (모든 기업이 동일하게 영향 받음)
  • 전국적 정책 변화

DiD가 통제하지 못하는 것 ⚠️

그룹별로 다른 시간 변화 추세는 통제되지 않습니다!

문제가 되는 경우:

  • 처치군이 속한 산업이 급성장 중 (대조군 산업은 정체)
  • 처치군 지역에 대규모 개발 사업 동시 진행
  • 처치군 기업들의 혁신 속도가 빠름

→ 이런 경우 평행 추세 가정이 위배되고 DiD 추정량이 편향됩니다.

🎨 Event Study Design

Event Study는 처치 전후의 동적 효과를 추정하는 방법입니다. DiD의 핵심 가정인 평행 추세를 시각적으로 검증할 수 있습니다.

Event Study 모형

Yit = αi + λt + Σk≠-1 βk·Ditk + εit

Ditk: 처치로부터 k 기간 떨어진 더미
βk: k 기간의 처치 효과
기준: k = -1 (처치 직전)

Event Study의 용도

1️⃣ 사전 추세 검증

처치 전 기간 (k < 0)의 βk가 모두 0에 가까우면 평행 추세 가정이 타당함을 시사합니다.

2️⃣ 동적 효과 추정

처치 후 각 기간 (k ≥ 0)의 효과를 개별적으로 추정하여 효과가 시간에 따라 어떻게 변하는지 파악합니다.

3️⃣ 예측 효과 탐지

처치 직전 기간에 효과가 나타나면 (anticipation effect) 이를 감지할 수 있습니다.

💻 Python 구현

1. 기본 2×2 DiD

Python 
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt

# 데이터 생성
np.random.seed(42)

# 패널 데이터: 2 그룹 × 5 시점 × 100 개체
groups = ['treated', 'control']
years = range(2018, 2023)
n_per_group = 100

data = []
for group in groups:
    for year in years:
        for i in range(n_per_group):
            treated = 1 if group == 'treated' else 0
            post = 1 if year >= 2021 else 0  # 2021년 처치

            # 반사실 결과 (처치 없을 때)
            # 그룹별 고정 효과 + 공통 시간 추세 + 노이즈
            y0 = 50 + 10*treated + 2*year + np.random.normal(0, 5)

            # 처치 효과 = 10
            treatment_effect = 10 if (treated == 1 and post == 1) else 0

            y = y0 + treatment_effect

            data.append({
                'id': f'{group}_{i}',
                'group': group,
                'year': year,
                'treated': treated,
                'post': post,
                'y': y
            })

df = pd.DataFrame(data)

# =====================================
# 방법 1: 평균 차이로 직접 계산
# =====================================

means = df.groupby(['treated', 'post'])['y'].mean()

treated_post = means[(1, 1)]
treated_pre = means[(1, 0)]
control_post = means[(0, 1)]
control_pre = means[(0, 0)]

did_manual = (treated_post - treated_pre) - (control_post - control_pre)
print(f"Manual DiD estimate: {did_manual:.2f}")

# =====================================
# 방법 2: 회귀분석
# =====================================

# DiD 회귀
df['treated_post'] = df['treated'] * df['post']

model = smf.ols('y ~ treated + post + treated_post', data=df)
result = model.fit()
print(result.summary())

print(f"\nDiD coefficient: {result.params['treated_post']:.2f}")
print(f"95% CI: [{result.conf_int().loc['treated_post', 0]:.2f}, "
      f"{result.conf_int().loc['treated_post', 1]:.2f}]")

# =====================================
# 방법 3: 고정효과 모델 (패널)
# =====================================

from linearmodels import PanelOLS

df_panel = df.set_index(['id', 'year'])

# 개체 고정효과 + 시간 고정효과
model_fe = PanelOLS.from_formula(
    'y ~ treated_post + EntityEffects + TimeEffects',
    data=df_panel
)

result_fe = model_fe.fit(cov_type='clustered', cluster_entity=True)
print(result_fe)

# =====================================
# 시각화
# =====================================

# 그룹별 연도별 평균
group_means = df.groupby(['year', 'treated'])['y'].mean().reset_index()

plt.figure(figsize=(10, 6))

# 처치군
treated_data = group_means[group_means['treated'] == 1]
plt.plot(treated_data['year'], treated_data['y'],
         marker='o', linewidth=2, label='Treated', color='#e74c3c')

# 대조군
control_data = group_means[group_means['treated'] == 0]
plt.plot(control_data['year'], control_data['y'],
         marker='s', linewidth=2, label='Control', color='#3498db')

# 처치 시점 표시
plt.axvline(x=2020.5, color='gray', linestyle='--', label='Treatment')

plt.xlabel('Year')
plt.ylabel('Outcome')
plt.title('Difference-in-Differences')
plt.legend()
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

2. Event Study 구현

Python 
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt

# 패널 데이터 생성 (여러 시점)
np.random.seed(42)
years = range(2015, 2024)  # 9년
n_per_group = 200
treatment_year = 2020

data = []
for treated in [0, 1]:
    for year in years:
        for i in range(n_per_group):
            # 처치로부터 떨어진 시간
            time_to_treatment = year - treatment_year

            # 기본 추세
            y0 = 50 + 10*treated + 2*year + np.random.normal(0, 5)

            # 처치 효과 (처치 후에만)
            if treated == 1 and year >= treatment_year:
                # 동적 효과: 처치 후 점진적으로 증가
                years_since = year - treatment_year
                treatment_effect = 8 + 2*years_since
            else:
                treatment_effect = 0

            y = y0 + treatment_effect

            data.append({
                'id': f'unit_{treated}_{i}',
                'treated': treated,
                'year': year,
                'time_to_treatment': time_to_treatment,
                'y': y
            })

df = pd.DataFrame(data)

# Event study 회귀
# k = -1을 기준(omitted)으로 설정
df['rel_time'] = df['time_to_treatment']

# 더미 변수 생성
for k in range(-5, 4):
    if k != -1:  # 기준 제외
        df[f'lead_lag_{k}'] = ((df['treated'] == 1) &
                                (df['rel_time'] == k)).astype(int)

# 회귀 실행
formula = 'y ~ ' + ' + '.join([f'lead_lag_{k}' for k in range(-5, 4) if k != -1])
model = smf.ols(formula, data=df)
result = model.fit(cov_type='HC1')

# 결과 추출
coefs = []
ci_lower = []
ci_upper = []
periods = []

for k in range(-5, 4):
    if k == -1:
        coefs.append(0)  # 기준
        ci_lower.append(0)
        ci_upper.append(0)
    else:
        coefs.append(result.params[f'lead_lag_{k}'])
        ci_lower.append(result.conf_int().loc[f'lead_lag_{k}', 0])
        ci_upper.append(result.conf_int().loc[f'lead_lag_{k}', 1])
    periods.append(k)

# 시각화
plt.figure(figsize=(12, 6))
plt.plot(periods, coefs, marker='o', linewidth=2, markersize=8, color='#2c3e50')
plt.fill_between(periods, ci_lower, ci_upper, alpha=0.2, color='#3498db')
plt.axhline(y=0, color='red', linestyle='--', linewidth=1)
plt.axvline(x=-0.5, color='gray', linestyle='--', linewidth=1, label='Treatment')

plt.xlabel('Time Relative to Treatment')
plt.ylabel('Coefficient')
plt.title('Event Study: Dynamic Treatment Effects')
plt.legend()
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

# 사전 추세 테스트
pre_treatment_coefs = [coefs[i] for i, k in enumerate(periods) if k < 0 and k != -1]
print(f"\nPre-treatment coefficients: {pre_treatment_coefs}")
print("All close to zero? → Parallel trends likely holds")

💻 R 구현

R 
library(fixest)
library(ggplot2)
library(dplyr)

# 데이터 생성
set.seed(42)

# 패널 데이터
data <- expand.grid(
  unit = 1:200,
  year = 2015:2023
) %>%
  mutate(
    treated = ifelse(unit <= 100, 1, 0),
    treatment_year = 2020,
    post = ifelse(year >= treatment_year, 1, 0),
    time_to_treatment = year - treatment_year,

    # 결과 변수
    y0 = 50 + 10*treated + 2*year + rnorm(n(), 0, 5),

    # 처치 효과
    te = ifelse(treated == 1 & post == 1,
                8 + 2*(year - treatment_year), 0),
    y = y0 + te
  )

# ====================================
# 기본 DiD
# ====================================

did_model <- feols(
  y ~ treated + post + treated:post,
  data = data
)

summary(did_model)

# ====================================
# 고정효과 DiD
# ====================================

# 개체 고정효과 + 연도 고정효과
did_fe <- feols(
  y ~ treated:post | unit + year,
  data = data,
  cluster = ~unit  # 개체 수준 클러스터링
)

summary(did_fe)

# ====================================
# Event Study
# ====================================

event_study <- feols(
  y ~ i(time_to_treatment, treated, ref=-1) | unit + year,
  data = data,
  cluster = ~unit
)

# 시각화
iplot(event_study,
      main = "Event Study: Dynamic Treatment Effects",
      xlab = "Time to Treatment",
      ylab = "Coefficient")

# 결과 확인
summary(event_study)

# ====================================
# 강건성 검증
# ====================================

# 1. Placebo test: 가짜 처치 시점
data_placebo <- data %>%
  filter(year < 2020) %>%
  mutate(
    fake_post = ifelse(year >= 2018, 1, 0),
    fake_treated_post = treated * fake_post
  )

placebo_test <- feols(
  y ~ fake_treated_post | unit + year,
  data = data_placebo
)

summary(placebo_test)
# 효과가 0에 가까워야 함 (처치 전이므로)

# 2. 다양한 시기 제외
# 첫 해 제외
did_robust1 <- feols(
  y ~ treated:post | unit + year,
  data = data %>% filter(year != 2020),
  cluster = ~unit
)

# 마지막 해 제외
did_robust2 <- feols(
  y ~ treated:post | unit + year,
  data = data %>% filter(year != 2023),
  cluster = ~unit
)

# 결과 비교
etable(did_fe, did_robust1, did_robust2,
       headers = c("Baseline", "Excl. 2020", "Excl. 2023"))

📚 실제 연구 사례

1. Card & Krueger (1994) - 최저임금과 고용

연구 질문: 최저임금 인상이 고용을 감소시키는가?

처치군: 뉴저지 (New Jersey) - 1992년 최저임금 $4.25 → $5.05

대조군: 펜실베이니아 (Pennsylvania) - 최저임금 변화 없음

결과 변수: 패스트푸드 레스토랑 고용

데이터: 처치 전 (1992.02) vs 처치 후 (1992.11)

핵심 발견:

  • 전통적 경제 이론: 최저임금 ↑ → 고용 ↓
  • Card & Krueger 결과: 최저임금 ↑ → 고용 변화 없음 또는 약간 증가!
  • 뉴저지 레스토랑 고용: 20.4 → 21.0 명 (+0.6)
  • 펜실베이니아 레스토랑 고용: 23.3 → 21.2 명 (-2.1)
  • DiD 효과: +0.6 - (-2.1) = +2.7 명 증가

영향:

  • 최저임금 연구의 패러다임 전환
  • 노동경제학에서 DiD 방법론 확산
  • 정책 논쟁에 실증적 근거 제공

2. Duflo (2001) - 인도네시아 학교 건설과 교육

연구 질문: 학교 건설이 교육 수준을 높이는가?

처치: 1973-1979년 인도네시아 대규모 학교 건설 프로그램 (INPRES)

처치 강도: 지역별로 건설된 학교 수가 다름 (DiD with continuous treatment)

결과: 교육 연수, 임금

핵심 발견:

  • 학교 2개 건설 → 교육 연수 약 0.12-0.19년 증가
  • 교육 1년 증가 → 임금 약 1.5-2.7% 증가
  • 교육 투자의 장기적 효과 입증

3. Autor (2003) - 부당해고 법과 고용

연구 질문: 고용 보호 법규가 고용 수준에 영향을 미치는가?

처치: 미국 주(state)별로 다른 시기에 부당해고 예외(wrongful discharge doctrine) 도입

설계: Staggered DiD (시차를 둔 처치)

결과: 고용률

핵심 발견:

  • 부당해고 보호 법 도입 → 고용 약 0.8-1.6% 감소
  • 고용 보호가 역설적으로 채용 감소 초래

🆕 최신 DiD 방법론

왜 새로운 방법론이 필요한가?

전통적 DiD는 2×2 설정 (2그룹, 2시점)을 가정합니다. 하지만 실제 연구에서는:

  • 처치 시기가 그룹마다 다름 (Staggered adoption)
  • 처치 효과가 시간에 따라 변함 (Dynamic effects)
  • 여러 시점, 여러 그룹

⚠️ TWFE의 문제점 (Goodman-Bacon 2021)

Two-Way Fixed Effects (TWFE) 추정량은 잘못된 가중치를 사용할 수 있습니다.

  • 이미 처치받은 그룹이 나중에 처치받는 그룹의 대조군이 됨
  • 처치 효과가 시간에 따라 변하면 편향 발생
  • 음(-)의 가중치 문제

1. Callaway & Sant'Anna (2021)

핵심 아이디어:

  • 처치 시기별로 그룹-시간 평균 처치 효과 (ATTgt) 개별 추정
  • 아직 처치받지 않은 그룹만 대조군으로 사용
  • 원하는 가중치로 집계 가능
R 
library(did)

# Callaway & Sant'Anna 방법
cs_result <- att_gt(
  yname = "y",
  tname = "year",
  idname = "unit",
  gname = "first_treat",  # 첫 처치 시기
  data = panel_data,
  control_group = "notyettreated"  # 아직 처치 안 받은 그룹만 대조군
)

# 시각화
ggdid(cs_result)

# 집계
agg_simple <- aggte(cs_result, type = "simple")
agg_dynamic <- aggte(cs_result, type = "dynamic")

summary(agg_simple)
summary(agg_dynamic)

2. Sun & Abraham (2021)

Interaction-Weighted Estimator:

  • 마지막에 처치받는 그룹(last treated)을 대조군으로 사용
  • 교호작용 가중 추정량
R 
library(fixest)

# Sun & Abraham 방법
sunab_result <- feols(
  y ~ sunab(first_treat, year) | unit + year,
  data = panel_data,
  cluster = ~unit
)

# 시각화
iplot(sunab_result)

3. Goodman-Bacon (2021) - DiD 분해

R 
library(bacondecomp)

# TWFE 추정량 분해
bacon_decomp <- bacon(
  y ~ treated_post,
  data = panel_data,
  id_var = "unit",
  time_var = "year"
)

# 시각화: 각 2×2 비교의 가중치
ggplot(bacon_decomp, aes(x=weight, y=estimate, shape=type)) +
  geom_point() +
  labs(title="Bacon Decomposition")

⚠️ DiD 사용 시 주의사항

1. 평행 추세 위배

문제: 처치군과 대조군의 사전 추세가 다르면 편향 발생

해결책:

  • Event study로 사전 추세 시각화
  • 유사한 추세를 가진 대조군 선택
  • 추세를 통제하는 모형 (group-specific linear trends)

2. Anticipation Effects (예측 효과)

  • 처치 발표 시점과 실제 시행 시점이 다를 때
  • 개인/기업이 미리 행동을 조정할 수 있음
  • 해결책: Event study로 탐지, 예측 기간 제외

3. Spillover Effects (파급 효과)

대조군이 처치군의 영향을 받으면 SUTVA 위배

예시:

  • 이웃 도시의 정책이 우리 도시에 영향
  • 경쟁 기업의 혁신이 우리 기업에 영향

4. Composition Changes (구성 변화)

  • 관측되는 개체 구성이 시간에 따라 변하면 문제
  • 예: 처치 후 고성과자만 남고 저성과자는 퇴사
  • 해결책: 균형 패널(balanced panel) 사용

5. Staggered Adoption 문제

  • 전통적 TWFE는 부적절한 가중치 사용
  • 해결책: Callaway & Sant'Anna, Sun & Abraham 등 최신 방법 사용

📝 퀴즈: 학습 내용 확인

Q1. DiD의 핵심 가정은 무엇인가요?

A. 처치군과 대조군의 사전 수준이 동일하다
B. 처치가 없었다면 두 그룹의 추세가 평행했을 것이다 (평행 추세)
C. 처치 배정이 완전 무작위다
D. 처치 효과가 시간에 불변이다
정답: B
DiD의 핵심 가정은 평행 추세(Parallel Trends)입니다. 처치가 없었다면 처치군과 대조군의 결과 변수 추세가 평행했을 것이라는 가정입니다. 사전 수준이 다른 것은 괜찮지만, 추세의 기울기가 같아야 합니다.

Q2. DiD가 자동으로 통제하는 것은?

A. 시간에 따라 변하는 모든 교란 변수
B. 시간 불변 그룹 차이와 공통 시간 추세
C. 그룹별로 다른 시간 추세
D. 처치 효과의 이질성
정답: B
DiD는 시간에 불변하는 그룹 간 차이(time-invariant group differences)와 모든 그룹에 동일하게 영향을 미치는 시간 효과(common time trends)를 자동으로 통제합니다. 하지만 그룹별로 다른 시간 추세는 통제하지 못합니다.

Q3. Event Study의 주요 목적은?

A. DiD 추정량의 표준오차를 줄이기 위해
B. 평행 추세 가정을 검증하고 동적 효과를 추정하기 위해
C. 더 많은 대조군을 찾기 위해
D. 처치 시점을 결정하기 위해
정답: B
Event Study는 처치 전후 각 기간의 효과를 개별적으로 추정합니다. 이를 통해 (1) 처치 전 기간에 효과가 0인지 확인하여 평행 추세 가정을 검증하고, (2) 처치 후 시간에 따른 동적 효과를 파악할 수 있습니다.

Q4. Card & Krueger (1994) 연구의 주요 발견은?

A. 최저임금 인상이 고용을 크게 감소시켰다
B. 최저임금 인상이 고용을 감소시키지 않았거나 오히려 증가시켰다
C. 최저임금이 임금에 영향을 미치지 않았다
D. DiD 방법론이 부적절하다
정답: B
Card & Krueger (1994)는 뉴저지의 최저임금 인상이 패스트푸드 레스토랑 고용을 감소시키지 않았다는 것을 발견했습니다. 이는 전통적인 경제 이론 예측과 달라 최저임금 연구에 큰 영향을 미쳤습니다.

Q5. 평행 추세 가정에 대한 올바른 설명은?

A. 처치 전 데이터로 완벽하게 검증 가능하다
B. 반사실에 대한 가정이므로 직접 검증 불가능하지만, 사전 추세 분석으로 간접 확인 가능하다
C. 두 그룹의 사전 수준이 같아야 한다
D. 처치 후 추세가 평행해야 한다
정답: B
평행 추세 가정은 "처치가 없었다면"이라는 반사실에 대한 가정이므로 직접 검증할 수 없습니다. 대신 처치 전 기간의 추세가 평행한지 확인하거나 Event Study로 사전 효과가 0인지 확인하여 간접적으로 검증합니다.

Q6. TWFE (Two-Way Fixed Effects)의 문제점은?

A. 계산이 너무 복잡하다
B. Staggered adoption 상황에서 부적절한 가중치를 사용하여 편향이 발생할 수 있다
C. 표준오차가 너무 크다
D. 평행 추세 가정이 필요 없다
정답: B
Goodman-Bacon (2021) 등의 연구에서 밝혀진 바와 같이, 처치 시기가 그룹마다 다른 staggered adoption 상황에서 전통적 TWFE는 이미 처치받은 그룹을 대조군으로 사용하는 등 부적절한 가중치를 사용하여 편향이 발생할 수 있습니다.

Q7. 다음 중 DiD 설계에 적합한 상황은?

A. 처치 배정이 완전 무작위인 RCT
B. 특정 지역에만 정책이 시행되고, 유사한 다른 지역이 대조군으로 존재
C. 단일 시점, 단일 그룹만 관측 가능
D. 처치군과 대조군의 추세가 반대 방향
정답: B
DiD는 특정 그룹(지역, 기업 등)에만 정책/처치가 시행되고, 처치받지 않은 유사한 대조군이 존재하며, 처치 전후 데이터가 모두 있는 상황에 적합합니다.
