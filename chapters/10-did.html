중급 - Chapter 10

이중차분법 (Difference-in-Differences)

패널 데이터에서 시간에 따른 변화를 활용한 인과추론

🎯 DiD의 핵심 아이디어

처치군과 대조군의 변화의 차이를 비교하여 인과 효과를 추정합니다. 시간에 불변하는 교란 변수를 자동으로 통제합니다.

DiD 추정량:

τ = (Ȳtreated,post - Ȳtreated,pre) - (Ȳcontrol,post - Ȳcontrol,pre)

평행 추세 가정 (Parallel Trends)

💡 핵심 가정

처치가 없었다면, 처치군과 대조군의 추세가 평행했을 것
= 시간에 따른 변화가 동일했을 것

⚠️ 검증 불가능: 반사실이므로 직접 확인 불가
대신 사전 추세(pre-trends) 분석으로 간접 확인

회귀 명세

Yit = α + βTi + γPostt + δ(Ti×Postt) + εit

δ: DiD 추정량 (처치 효과)

Python 
import pandas as pd
from linearmodels import PanelOLS

# DiD 회귀
data['treated_post'] = data['treated'] * data['post']

model = PanelOLS.from_formula(
    'Y ~ treated + post + treated_post + EntityEffects + TimeEffects',
    data=data.set_index(['id', 'time'])
)
result = model.fit(cov_type='clustered', cluster_entity=True)
print(result)
